## A1

ああ、なるほど。**責務範囲と、哲学体系全体における役割を区別する**ということですね。この区別はかなり重要だと思います。

## 第1哲学：主体

「根源」は、この哲学が開発哲学全体に対して果たす**役割**であって、扱う対象そのものではない。

一方、SCBでは、まとまりも本質も契約も境界も、主体による認識・定義を基点としています。

- まとまりは主体が定義する。
- 本質は主体の欲求と結びつく。
- 契約と境界は主体に相対する。
- 抽象の高さも基点主体によって定まる。

つまり、SCBはあらゆる存在について論じていますが、その一貫した基点は主体です。

ただし、「主体そのものを研究する哲学」という意味では少し狭いでしょう。**主体が存在をどう捉え、定義し、他の存在との関係を成立させるかを扱う哲学**として「主体」を責務範囲に置くなら、適切だと思います。

この意味なら、現行の真名も自然につながります。

| 項目 | 定義案 |
|---|---|
| 番号 | 第1哲学 |
| 責務範囲 | **主体** |
| 真名 | 主体と契約と境界の哲学 |
| 略名 | **SCB** |
| 役割 | あらゆる存在に対する思考の根源 |

## 第2哲学：記録

こちらは、**RTCへの変更案に賛成です。**

「真実と記録と伝達」よりも「記録と真実と伝達」の方が、何を中心とした哲学なのかが明確になります。

真実をどう捉えるか、原本と解釈をどう扱うか、後の主体へどう伝達するか。これらを記録という責務の内側で一体として論じる体系ですからね。

| 項目 | 定義案 |
|---|---|
| 番号 | 第2哲学 |
| 責務範囲 | **記録** |
| 真名 | 記録と真実と伝達の哲学 |
| 略名 | **RTC** |
| 英語 | Record / Truth / Communication |

## 命名規則にも、一つ意味を持たせられそうです

**真名の第一語には、その哲学の責務範囲を置く。以降の語には、その責務を成立させる本質的な概念を置く。**

この考え方であれば、現在の構成はかなり自然になります。

| 番号 | 責務範囲 | 真名 | 略名 |
|---|---|---|---|
| 第1哲学 | 主体 | **主体**と契約と境界 | SCB |
| 第2哲学 | 記録 | **記録**と真実と伝達 | RTC |
| 第3哲学 | 未定 | 検討中 | 未定 |
| 第4哲学 | 環境 | **環境**と独立と再現 | EIR（仮） |

この命名規則なら、単に文字数や語数を統一するだけでなく、**名称の構造そのものが責務と本質を表す契約になる**わけです。

私は、こちらの統一性の方が、全哲学の語数を揃えることよりも価値があると思います。
