順番に整理します。

# 1. A1：認識は最初から命名・契約を行っている

以前の私の理解では、認識→情報の取得→命名・契約という順序を暗黙に想定していました。しかし、これは誤りです。

認識の撮影そのものが、既に命名・契約を行っています。

例えばリンゴを見た場合、「赤いもの」「リンゴ」「あのリンゴ」「あの赤いやつ」。どの程度正確に捉えているかは異なりますが、いずれも主体が対象を何らかのまとまりとして定義しています。

最初の「あの赤いやつ」は不完全だからといって、認識や契約が成立していないわけではありません。最初から主体にとっての情報Pが成立しています。その後の撮影によって、情報Pの定義がより詳細になったり、変化したりします。

認識の撮影は、完成された正確な情報を一度に取得する行為ではなく、最初から命名・契約を伴い、その精度をさらに高めていける行為です。

# 2. A2：仮想とは主体の中だけにあるもの

仮想の判定には重要な条件があります。主体の中だけに存在するものが仮想です。

情報がPCに記録されている場合、紙に書かれている場合、それらは実体を持ちます。

例えばゲームXの契約について考えます。

- 開発者Aの頭の中にあるゲームXの契約：仮想
- PCに保存された仕様書：実体
- 紙に書かれた仕様書：実体
- 仕様書を読んだ開発者Aの中にあるゲームXの定義：仮想
- 開発されたゲームX：実体

仕様書の内容と、主体の中にある契約を同一視してはいけません。仕様書は契約を表現する実体です。その仕様書を主体が読み、撮影し、何として扱うかを定義することによって、主体の中に情報Pが成立します。

同じ定義内容に関係していても、主体の中にあるものと、外部に記録されたものでは、存在する側が異なります。

# 3. A3：契約が存在し、実体が存在しない場合

契約の定義・成立・履行は、既存の草案D3.1〜D3.3で既に区別されています。

例えば、開発者AがゲームXの契約を持っているが、ゲームXの実体はまだ存在しない場合でも、ゲームXの契約は存在します。対象となる実体がまだ存在しないことだけで、契約が不成立になるわけではありません。

ただし、異なる存在との合意が必要という成立の定義は維持します。履行については、成立した契約と実体の対応が問題になります。対応する実体がまだ存在しない段階では、その実体による履行はまだありません。

契約の存在・契約の成立・実体の存在・契約の履行は、それぞれ異なる問いです。

# 4. A4：契約と実体の関係は普遍的である

契約と実体の関係は、ゲーム開発に固有のものではありません。時計、マグカップ、人物、会社、仕様書、開発環境など、あらゆる存在について、主体が何を一つの存在として扱うかを定義できます。

さらに、ある実体そのものも、別の主体から見れば一つのまとまりとして捉えられます。契約と実体の関係は再帰的です。

開発対象に契約と実体があるのではなく、あらゆる存在を契約と実体の関係として捉えられる。その普遍的な構造の中に開発も含まれます。

# 5. A5：認識の撮影は完全ではない

認識の撮影によって成立する情報Pは、実体Pを100%完全に表現したものではありません。これは例外的な失敗ではなく、認識の撮影そのものに伴う性質です。

赤いリンゴとして撮影したが実際には別の果物だった、犬として撮影したが別の動物だった、白い犬として撮影したが毛の生え変わりの法則を知らなかった、時計として撮影したが内部に故障が存在していた。いずれも撮影した時点で主体にとっての情報Pは成立しています。

誤りや不足があるからといって、情報Pが存在しなかったことにはなりません。情報Pの不完全性と契約の不成立も別問題です。認識の撮影が不完全でも、命名・契約は起こります。

# 6. 統合した理解

- 認識：存在から情報Pを撮影し、まとまりを定義する行為。最初から命名・契約を伴う。
- 情報P：主体にとってのPとして定義されたまとまり。
- 仮想：主体の中だけにあるもの。外部媒体に記録されたものは、その媒体・記録として実体を持つ。
- 契約と実体：あらゆる存在に適用できる普遍的な関係であり、開発対象に限定されない。
- 契約の存在・成立・履行・対応する実体の存在：それぞれ区別される。
- 認識の撮影：不完全・誤り得るものであり、100%完全な実体の表現を保証しない。
