# 第1哲学　主体と契約と境界の哲学（SCB）

学校の壁に取り付ける時計を考える。生徒には、時刻を知るための時計が一つあればよい。時計を作る人には、文字盤や計測機構がそれぞれ果たすべき仕事がある。校舎を建てる人には、壁に何を取り付け、どこまでを建築の責任として引き受けるかが問題になる。同じ場所の同じ実物を扱っていても、必要な境界は異なる。

SCB（Subject / Contract / Boundary）が担うのは、主体があらゆる存在について考える出発点である。ある主体が何を求め、何を一つの存在として定め、その存在に何を託すかを扱う。名前が表す責務を他の存在と確かめ合えるからこそ、各々が相手の内部の作り方まで引き受けずに協力できる。この関係は、道具を作る場合にも、組織に役割を設ける場合にも、制度を定める場合にも問題になる。

## 問いをどう吟味するか

同じ言葉でも、日常の用法や他の哲学での定義と、SCBでの定義は違い得る。例えば「契約」と聞いて署名を思い浮かべても、署名の有無だけでは、時計を何として定義したか、その扱いについて誰と合意したかは分からない。比較のときには双方の言葉の意味を示し、SCBについての判断には、ここで定めた意味と概念どうしの関係を使う。

「故障した時計はもう時計ではないのか」という問いには、契約の意味と履行を区別すれば答えられる。どんな状態を故障と呼ぶかは当の契約が定め、どんな試験で故障を確かめるかは対象に応じて決める。定義に明示されている答え、複数の定義から導ける答え、実現方法の選択に属する問いでは、必要な判断が違う。普遍的な関係について定義を合わせても答えが出なければ、どの前提が足りないかを示し、哲学の策定者の判断に委ねる。矛盾があるというには、同じ主体・意味・条件のもとで、両立しない二つの主張が導かれることを示す必要がある。

境界の堅牢さや再定義についての判断指針も、領域をまたいで成り立つ意味を扱う限りは哲学に含まれる。特定の規格を選ぶ基準、運用の手順、検証の方法は、その意味を各領域で実現する方法論に属する。
