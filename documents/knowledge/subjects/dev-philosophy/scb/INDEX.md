# 第1哲学　主体と契約と境界の哲学（SCB）

学校の壁に取り付ける時計を考える。生徒には、時刻を知るための時計が一つあればよい。時計を作る人には、文字盤や計測機構がそれぞれ果たすべき仕事がある。校舎を建てる人には、壁に何を取り付け、どこまでを建築の責任として引き受けるかが問題になる。同じ場所の同じ実物を扱っていても、必要な境界は異なる。

SCBは、ある主体が何を求め、何を一つの存在として定め、その存在に何を託すかを扱う。名前が表す責務を他の存在と確かめ合えるからこそ、各々が相手の内部の作り方まで引き受けずに協力できる。この関係は、道具を作る場合にも、組織に役割を設ける場合にも、制度を定める場合にも問題になる。
