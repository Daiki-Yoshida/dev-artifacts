# 第1哲学　主体と契約と境界の哲学（SCB）

街で時刻を知りたい人と、塔に時計を据え付ける人とでは、同じ時計を前にしても、何を一つと数えるかが違う。前者には時刻を知らせるものが一つあればよい。後者には、時計が塔とどう接し、どこまでを時計の製作者に託せるかという境界がある。文字盤の内側にも、製作者が責任を負う別のまとまりがある。どの境界が意味を持つかは、何を求めて対象に関わる主体かによって決まる。

**主体と契約と境界の哲学（Subject / Contract / Boundary、SCB）の責務範囲は主体である。** すべての存在を考える根源として、何をどんな意味の存在として認め、その存在が他とどのような関係を結び得るかを扱う。そこで定めた責務を独立して引き受けられるよう境界を選び、実態と合わなくなったら何を保ち、何を定め直すかを考える。環境を扱うときにも、記録を残すときにも、目的が実現したかを判断するときにも、まず、誰にとって何が問題なのかというこの問いがある。

| 章 | 主題 | 中心となる問い |
| --- | --- | --- |
| 0 | [本体系の前提と読み方](READING.md) | 言葉の意味や判断の範囲を、どの立場から確かめるか。 |
| 1 | [まとまりと定義](UNITS_AND_DEFINITIONS.md) | 何が認識され、何に名前・本質・境界が定まるか。 |
| 2 | [主体・欲求・責務](SUBJECTS_AND_RESPONSIBILITIES.md) | 誰が何を求め、誰の立場で何を引き受けるか。 |
| 3 | [契約と内部自由](CONTRACTS.md) | 内容の定義、合意による成立、実態による履行はどう違うか。 |
| 4 | [相互作用と実態](INTERACTIONS.md) | 定義はどのように現実の作用に関わり、他の契約にも影響するか。 |
| 5 | [境界面理論](BOUNDARIES.md) | どの幅の内側で、何を分け、何を一緒に担うか。 |
| 6 | [乖離と再定義](REDEFINITION.md) | どこで食い違いが起き、誰がどの境界を引き直せるか。 |

章順は概念を理解する順である。具体的な開発で常にこの順序の作業が必要になるわけではない。[哲学上の比較](COMPARISONS.md)では、意味の使用、約束、人工物の機能という問いを通じて、他の考え方との接点と違いを扱う。
