# 契約と相互作用

## 定義・成立・履行

契約は、ある存在が他の存在に対して何を意味し、どう扱われ、何を引き受けるかを仮想の上で定める。これにより、相手は内部の事情を一つずつ調べなくても、その存在に何を期待できるかを知り得る。ここでは、契約について次の三つの問いがそれぞれ意味を持つ。

| 問い | 時計を届ける場合 |
| --- | --- |
| **定義**　何を引き受ける存在として名付けたか。 | 時刻を知るために使えるものを時計と定める。 |
| **成立**　その存在と関わる別の存在との間で、どの扱いが合意されたか。 | 作る側と使う側が、この時計から時刻を読み取れることを約束する。 |
| **履行**　実際の状態や振る舞いが、成立した契約を満たしているか。 | 届いた時計を用いて、約束したとおり時刻を知ることができる。 |

時計がまだ実在しない段階でも、何を届けるかについては合意できる。完成品が手元にあっても、壊れて時刻を読めなければ、合意はあって履行を欠く。逆に、ある人が一人で考えた時計の定義から、依頼を受けていない人が作る責務まで導くことはできない。定義は仮想上にあり、当事者は仮想上で相手の意味を確かめ合う。履行を判断する先は実態である。

合意は一対一にも、一対多や多対多にも成立し得る。その主体を担う物理的な個体の数だけで判定はできない。同じ人が製作と利用の二役を担うときにも、どの責務どうしの関係かを区別する。仕様を公布する、部品規格を団体で定める、権限のある者が法律を公布するといった手続きの効力は、それぞれの領域で定まる。SCBはこれら全てに同じ形式の同意を要求しない。

## 物理的な作用に意味を与える

音が伝わるために人間の契約は要らない。ある音を警報として用い、聞いた人が避難するという新しい関係を作るには、何を知らせる音で、どう応じるかを定める必要がある。同じ振動が、別の人には騒音にしか聞こえないこともある。定義は自然現象を発生させる条件ではなく、開発によって新しい意味ある相互作用を成立させる条件である。何と何の間にどんな作用を認めるかについても、主体と粒度が関わる。

二つの契約が一つの実物に依存するとき、この違いが現実の結果に表れる。道端の棒を日時計にする人と、道標にする人は、それぞれの用途を正しく理解していても相手の用途を知らないことがある。道標を見やすくする照明が棒の影を消せば、道標には改善でも日時計には支障が出る。一方の契約にとっての内部変更が、他方の契約の履行を損なったことになる。

共有を予定しているなら、影で時刻を読め、遠くから道標として見つけられることまで共通の契約にできる。共有に気付いたのが後なら対応の起点も変わる。別々の井戸を用いてきた二つの集落が、渇水の年に初めて同じ地下水をくみ上げていたと知る場合、相互の影響はすでに起きている。そこで共通利用の条件を定められるが、新しい取り決めを、過去にも成立していた約束として扱うことはできない。

## 委ねた判断が生む拘束

内部の選択を任された主体が、その選択によって下位の主体の条件を定めることがある。本部が各支部に点検の記録を求め、様式については支部に判断を委ねたとする。支部が記入項目を決めれば、担当者にはその項目を埋める責務が生じ得る。支部に選択権があったことは、担当者が選択後の項目を自由に省けることを意味しない。

規則の適用対象か、どこまでが義務か、どの選択が誰に委ねられたか、実行する権限を持つかはそれぞれ確かめる必要がある。記入漏れによる損害が小さくても義務は消えず、記録が重要であっても担当者に外部公表の権限が生じるわけではない。
