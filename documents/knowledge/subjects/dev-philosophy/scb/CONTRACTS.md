# 契約と内部自由

## 契約内容を定めること

時計という名で、時刻を知ることのできる存在を定めたとする。何を時計として扱い、他の存在はそこに何を期待できるかが、その主体の内に定まる。こうして、ある存在の名前、本質、境界を定め、別の存在との関係でどう扱われるものかを規定する仮想側の定義が**契約**である。対象となる製品がまだ現存していなくても、その意味も契約内容も定められる。ソフトウェアの関数名や引数と戻り値、公開される接続仕様、部品規格は、内容を表す形式になり得る。

ここで契約という語が含むのは、名付けた存在が他に対して引き受ける意味までである。一人の主体のうちに契約内容があることから、別の存在もそれに合意したことや、実物がその内容に応えたことはまだ導けない。

## 異なる存在との合意が何について成立するか

**契約の成立**には、その契約が対象とする存在とは異なる存在との合意が要る。関係に与える意味は仮想の側にあるが、合意は、どの存在どうしが何について、どの権限、表現、対象、状況のもとで結び付いたかという具象とともに成立する。独立に同じ考えを思いついたという内心の一致だけでは、合意が形成されたことにならない。

例えば、ソフトウェアの利用者に仕様を公開する場合と、製造者の団体が部品規格を定める場合では、合意の現れ方が違う。権限者が公布することで規定が成立する仕組みなら、その具体的な公布が意味を持つ。全員による個別の再確認は一律の成立条件ではない。一対一、一対多、多対多のいずれもあり得る。どの役割の間にどんな関係があるかを捉えることと、異なる二個体を数えることも同じではない。合意形成や相互確証、成立を検証し運用する方法は、領域ごとの手段と権限に即して開発方法論が扱う。

まだ遊べるゲームがなくても、あるゲームを開発するという契約は関係者の間に成立し得る。反対に、実物があるだけでは、誰が何を引き受けたかは分からない。内容を変える場合も、相手がすでに任せた変更の範囲であれば、その合意によって判断できる。範囲を越えて違う保証や責務を求める場合は、変更後の関係を支える合意が必要になる。

## 実態による履行と、その確認

**契約の履行**は、成立した契約の対象となった実態が、そこで引き受けた責務に実際に対応している状態である。検証はその状態を知るための行為であり、検証した人が正しいと信じたこと自体は、状態を変えない。

| 状況 | 判断できること |
| --- | --- |
| 時計の仕様を定めたが合意はなく、たまたま仕様どおりの時計がある。 | 定義と実物の適合はある。履行した契約が成立しているとは言えない。 |
| まだ存在しない時計の製作について合意した。 | 成立した契約がある。将来の時計の実態による履行はまだない。 |
| 合意された時計が止まり、誰も故障に気づいていない。 | 合意はあっても、時刻表示を引き受けた時計に不履行が生じている。 |
| 通行人が別の時計を見て時刻を知った。 | 通行人の目的が満たされたことは、故障した時計が自分の契約を履行した根拠にならない。 |

## 契約に相対的な内部の自由

時刻の読み取れる時計塔を建てる契約が表示方式を指定していないなら、建設者は機械式、電子式、映像表示などを選び得る。その選択が上位の契約の内側で自由であることを**内部自由**という。機械式時計を作る契約を結んだ職人にとっては、方式は既に守る条件であり、材質を取り決めていなければそこにはなお選択が残る。どの主体のどの契約に照らすかで自由な内側が変わる。この性質が**内部自由の契約相対性**である。

建設者の決めた方式に従うことを職人が引き受けていれば、建設者が機械式を選んだ時点で、その選択は職人の具体的な履行条件になる。建設者が方式を決められるという上位の合意だけから、別の主体の義務までは発生しない。支部に点検項目の設定を任せる場合にも、選択を任された支部と、その項目に従う義務を引き受けた担当者を区別できる。規則の適用範囲と拘束の強さ、決定を任せた相手、実行権限はそれぞれ契約に照らす。記入漏れの被害が小さくても義務は消えず、重要な記録を扱うことから外部に公表する権限が生じるわけでもない。

契約で方式を定めていなくても、設置条件のため実際に使える方式が一つしかないことがある。これは実現上の制約である。他の契約が方式を定めていれば、それも別の関係として働く。また、下位の時計を別方式に定め直しても、時計塔として約束した意味を保てれば、上位には内部変更で済む。下位の相手との合意まで自動的に変更されるわけではない。このように、自分の責務を独立して引き受け、その内側を自由に構成できることには、それ自体に価値がある。交換や変更がしやすいこと、効率や生産性が上がることは、その結果として得られ得る。
