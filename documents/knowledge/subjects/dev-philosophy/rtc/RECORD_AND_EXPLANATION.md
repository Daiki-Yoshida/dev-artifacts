# 保存と説明の責務

## 求めることに応じて何を保持するか

過去の判断を保存する人と、その判断を今使う人が、同じ情報に求めるものは異なる。たとえば、条件つきで採用された方式を新人に説明するときは、今使う方式と、それを使える条件から示せばよい。なぜその条件が付いたのかを調べる人には、当時の反論と評価が要る。反論も含めて議論を保存しておけば、この二つの欲求に応じて異なる説明を組み立てられる。

| 目的 | 後の主体に必要な情報 |
| --- | --- |
| 対象をよりよく理解する | 異なる解釈が何を捉え、どこで反証されたか。 |
| 当時の判断を確かめる | 実際の表現と、誰が何を根拠にそれを評価したか。 |
| 今の判断を知る | どの条件に適用できるか。その後に何が訂正・採用されたか。 |
| 活動を途中から続ける | 今どこまで進み、何を引き継ぎ、次に何を決めるか。 |
| 過去の操作や状態を再現する | 何を再現対象とし、その成立にどの入力・条件・手順が関わったか。 |
| 得られた理解を他の主体へ渡す | その相手の目的に必要な意味と、それを誤用せずに判断できる条件・根拠。 |

説明を分かりやすくするために、順序を変えたり、同じ意味を違う表現で示したりできる。この自由は、元の字句を保つ責務にまで及ばない。一つしかない記録を読みやすい要約で置き換えると、読みやすさは増しても、当時の表現に戻って確かめる用途を失う。保存と説明に別々の文書を使う場合も、説明がいつのどの判断を整理したものかを特定できれば、必要な人は経緯を辿れる。すべての読者が一度に経緯の全体を読む必要はない。

## 取得・保持・伝達できる範囲

記録ができたという事実、その内容が対象に忠実であること、記録の作成と提供が取り決めに適うことは、それぞれ問う相手が違う。認証の成功を記録するために、そこで使われた秘密の値まで取得・保持する権限があるとは限らない。その値を共有先に保存した後で閲覧用の説明に伏せ字を使っても、すでに共有先へ渡った値まで取り戻せるわけではない。

無記名投票で、集計者は各票を読み、得票数を公表するとしよう。集計が票を正しく数えていても、投票者の氏名と各票を結び付けて記録すれば無記名の約束を損なう。得票数を公表する取り決めから、全員が原票を閲覧できるとは言えない。集計の正確さとは別に、誰が何を入手し、どう保持し、誰に何を知らせるのかが関わっている。

さらに、誰がどの票を投じたかの対応表を作らないという約束と、個々の選択が結果からも推測できないという約束とでは、守るべき範囲が変わる。投票者が全員同じ案を選んだとき、参加者と得票数を知る人には一人ひとりの選択が分かる。後者の秘匿まで引き受けた場合は、保存した項目だけでなく、公表した結果から受け手が知り得ることにも目を向ける必要がある。

## 再現と再開を支えるもの

過去の操作を再現したいときは、対象の版や入力など、求める結果を再び生じさせるための条件が問題になる。活動を再開したいときは、次の担い手がその目的に照らして何を引き継ぎ、どこから次の行為を決められるかが問題になる。研究の問いを練っている途中なら、調べたい問いには合意し、対象とする範囲は未決だと分かれば、議論をそこから再開できる。

複数の資料に基づいて再開地点をつかむなら、それぞれが何についての、いつの状態を示すのかを確かめる。最新の成果物に旧版の検証結果が添えられていた場合、どの時点のどの部分が検証済みかを知るには、検証した版とその後の変更を照合する。再開用の説明は過去の経過を整理した解釈であり、同時に、引継ぎの時点で担当者が状態をどう表したかを示す原本にもなる。その説明から現在地をつかみ、必要なときは根拠となった判断や観測に戻り、現在の実態と照らし合わせられることに意味がある。

前日の作りかけの器を手に取って土の乾き具合を確かめれば、陶工はそのまま成形を続けられることがある。一方、別の陶工が、前任者がなぜその形を選んだかまで引き継ぐには、器の今の姿だけでは理由が分からない。作業できる実際の状態を維持・再形成することと、必要な判断の根拠を後任に伝えることでは、必要な条件が違う。どの媒体・手順でこれを実現するかは、個々の活動の方法論に委ねられる。

## 必要な説明への到達

後の主体に判断を引き継ぐなら、その人が必要なときに記録の所在、対象、時点、現行の判断とその適用範囲を見分けられることも伝達の一部になる。例外の存在をすでに知っている人だけが、その例外の説明を見つけられる状態では、初めて対象を扱う人は、いつ調べ直すべきか判断できない。ある説明を共通の入口と定めれば、複数の主体が同じ表現を手掛かりに判断できる。ただし、基準として採用された説明にも、適用範囲や訂正の経緯がある。その説明が今も対象の実態に適うかは、入口としての位置づけとは別に確かめる。

## 探索の型と、伝達の鍵

誤った考えも、いったん提示されれば受け手の認識の対象になる。誤情報の「重さ」とは、誤りだという評価を添えても、その内容自体が後の理解や判断に関わり得るという意味である。単語数やデータ量の尺度では、その作用を量れない。どれほど強くどのように作用したかは、実際の受け手や状況による。

真実を探っているときは、うまく説明できなかった候補について、どの意味・条件・観測と合わなかったかを調べることで、求めているものの輪郭が分かってくる。誤情報が探索の型として役立つのは、対象とそうでないものの境界を捉えられるからである。誤った候補の数を増やせば自動的に真実に近づくとは言えない。

輪郭が捉えられた後、その内容を使いたい人には、得られた理解を直接伝えられる。探索に使った型をすべて渡せば、受け手は不要な区別まで扱うことになる。それでも、原本に保存された主張はそのまま採用されるものだと思い込んでいる人には、ある誤報の正確な記録が役に立つ。記録の忠実さと主張の採用との境目を見せる反例が、理解の鍵になるからである。探索で用いた型のうち何を今の受け手に渡すかは、誤解の中身と伝達の目的を見て決める。
