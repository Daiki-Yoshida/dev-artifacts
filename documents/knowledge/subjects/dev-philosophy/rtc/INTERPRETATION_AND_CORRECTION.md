# 解釈の忠実性と後の説明

発言の意味を扱うなら、解釈の良し悪しを決めるのは、当時の発言者が伝えようとした意図をどれだけ汲めたかである。皮肉をこめた褒め言葉を一字一句再現しても、称賛として受け取ったなら意図を外している。別の言葉で何を批判したのか説明できる方が、その意図に忠実なこともある。複数の解釈が成り立つことから、それらが同じ程度に妥当だとは言えない。

| 知りたいこと | 照らし合わせるもの |
| --- | --- |
| 何と発言したか | 記録に残った字句と、当時実際に表現された字句 |
| 何を伝えようとしたか | 読み取った意味と、当時の発言者の意図 |
| 主張や観測値は事実に適うか | 言葉や値が示す内容と、対象の当時の実態 |
| 今の判断にも使えるか | 採用しようとする内容と、現在の目的・根拠・適用条件・その後の採否 |

無人の水位計に午前3時の値として2メートルと表示されたとする。当時の出力を正確に保存できたかと、川の水が実際にその高さに達したかでは確かめ方が違う。後者には、どの高さを基準にしたのか、当時の計器に異常がなかったかも関わる。その場でこの水位を認識した人がいなくても測定値は成立する。設置者の意図が手掛かりになるのは、何のための観測だったかを問うときである。ある時刻の値が欠けていれば、水位がゼロだったか、観測できなかったか、測った結果が失われたかを、空欄だけからは決められない。

## 本人の後の言葉をどう読むか

意図は、当時の言葉が誰に向けられ、何について、どんな状況で発せられたかをもとに探れる。本人が後に説明したことも重要な手掛かりになる。これらは当時の意図を理解するための材料である。解釈者の思いついた筋書きが整っていても、本人が実際に示した条件や定義をそれで置き換えることはできない。本人が語り直すときにも、その人は今の事情と記憶のもとにいる。現在の方針を変える権限を持つことによって、過去についての記憶まで正確だと決まるわけではない。

たとえば最初は金曜までと告げた依頼者から、その後、月曜という期日が示されたとする。何を改めるべきかは、二つの日付がどう関係していたかで変わる。

- 金曜は内部での確認日、月曜は提出日だと分かったなら、以前からあった二つの期限を区別できるようにした**補足**である。
- 提出日はもともと月曜だったのに、本人が金曜と言い間違えたのなら、当時の認識や表現への**訂正**である。
- 当初は金曜に必要だったが、日程が延びたなら、金曜は当時の有効な期限であり、月曜は現在の要求への**変更**である。

一度の説明で内部確認の意味を補い、同時に提出日を変えることもできる。二つの期限を決める必要があると後になって初めて気づいたなら、具体的な区別を当初からの意図にさかのぼって帰すべきではない。過去の内面を完全に復元できなくても、どの時点の、どの対象について、どんな違いが生じたかは前後の表現から吟味できる。
