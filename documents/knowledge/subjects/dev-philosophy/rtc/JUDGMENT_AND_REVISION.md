# 解釈の忠実性と後続の説明

## 正しさを何に照らして問うか

発言の意味を解釈するとき、その良し悪しを決めるのは、発言者がそこで伝えようとしたことをどれほど汲めているかである。皮肉で述べた賛辞を一字一句正確に繰り返しても、素直な称賛として理解すれば意図を外す。その場で何を批判したのかを違う言葉で説明する方が、意図に忠実な場合がある。複数の読み方ができることと、そのどれもが同程度に妥当であることは別である。

「正しく記録されている」という判断が何を支えるかは、そのときの問いによる。

| 問いの例 | 確かめる対象 |
| --- | --- |
| 何と発言したか | 当時の表現と、保存された表現の一致 |
| 何を伝えようとしたか | その発言が向けられた相手・対象・状況と、解釈した意味との対応 |
| 主張や観測値は事実に合うか | 述べた内容や測った値と、その時点の対象の実態との対応 |
| 今この判断を採用できるか | 今の目的、当時の適用条件、その後の訂正や採否 |

たとえば完了の報告が誤っていても、その報告があったことは正確に保存できる。また、無人の水位計が午前3時に2メートルを示した場合、その出力を忠実に保存できたかは、当時の水位が正確に測れたかとは異なる。後者では、測定の基準面や計器の状態も確かめる。設置者の意図はなぜ水位を測るのかを説明するが、その人が午前3時に水位を認識したことは測定値の成立条件ではない。値のない欄だけから水位ゼロ、未観測、転記漏れのいずれであったかを決めることもできない。

## 後から明確になったことの扱い

本人が当時から意味を明瞭に区別できていたとは限らない。後になって適切な言葉を見つけたとき、その説明は過去を理解する助けになる。ただし、後の説明にある区別をすべて当初にさかのぼって帰すと、そのときは未確定だった部分まで確定してしまう。当時の対象・表現・対話に後の説明を照らす。読み手の推測した意図を、本人が実際に示した定義や条件より強い根拠としては扱えない。

たとえば金曜という期日の後に、同じ依頼者が月曜という日を示したとする。

| 前後の事情 | 何が変わったか |
| --- | --- |
| 内部確認は金曜、提出は月曜という予定だった。 | 区別されていなかった二つの対象が説明され、元の意図が明らかになる。 |
| 本来の提出日は月曜で、依頼者が日付を取り違えていた。 | 当時の認識や表現が訂正される。 |
| 金曜に必要だったが、その後の予定変更で月曜まで待てるようになった。 | 当時の要求はその時点では有効で、現在の要求が更新される。 |

一つの説明で、内部確認の目的を補足し、同時に提出日を変更することもある。その関係は、誰が先に話したかだけでは決まらない。本人は現在の要求を変更する権限を持つ場合にも、過去のことは今の立場と記憶から説明している。当時の内面を完全に復元できなくても、何を説明したのか、どの時点の何を改めたのかは、両時点の表現を手掛かりに検討できる。
