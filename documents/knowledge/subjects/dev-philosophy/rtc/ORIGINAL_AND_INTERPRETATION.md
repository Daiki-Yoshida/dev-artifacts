# 原本と解釈

## 主体の外に残るもの

主体は、ある時点の関心や立場から対象を捉え、発言や文章としてその一部を表現する。記録すると、その表現には、発言者が覚え続けなくても後から確かめられる実体ができる。ここで主体の内にある意図が丸ごと外へ移ったわけではない。言葉を選ぶ際に明確だったこともあれば、まだ言い分けられなかったこともある。

記録する必要は、この隔たりと時間の両方から生じる。後日の本人は、忘れたこと、新しく学んだこと、その間に変わった欲求を抱えて当時を振り返る。外に残した表現があれば、今の記憶と別に、当時何と言えたかを確かめられる。書きながら初めて自分の欲求を言い表せたり、読み返して曖昧さに気づいたりもする。主体が変化するために記録が要る一方で、記録を認識し直すことも主体を変える。

## 同じと言える範囲

あることが実際に起きたという事実は、後でその出来事をどう理解したかによって変わらない。ただし、主体が扱えるのは、自分が認識したこと、表現されたもの、そこから読み取ったことだ。原本は、このうち、当時何がどのように表現されたかを確かめ直す基点を与える。

原本と解釈を比べるときは、字句の一致と意味の一致を分ける。一字を変えた文章を、元の字句を完全に再現したものとして扱うことはできない。意味がよく通る言い換えでも、この基準に例外は生じない。忠実な複製は字句を完全に保持できるが、複製された媒体と作られた経緯を持つ。同じ文字列か、同じ実体か、同じ意味を伝えているかには、それぞれ異なる答えがあり得る。

発言の意図については、複数の解釈に優劣がある。たとえば皮肉で表された賛辞は、語をそのまま褒め言葉として読めば意図を外す。違う表現で批判の意味を説明した方が、発言者が伝えようとしたことに忠実な場合がある。何について、どのやり取りに応じて発した言葉かが、その判断を支える。短い同意の発言は、一語も欠かさず残しても、同意された案がどれか、どこまでを認めたかによって意味が違う。発言者・相手・対象・時点とその関係も、理解を支える情報である。

意図を地形にたとえると、同時点の表現は、後からその地形を調べるための一次の地図に当たる。簡略図は道を探す人を助けるが、作り手の目的に沿って目印を選んでいる。簡略図だけを引き継ぐと、別の人が別の問いを持ったとき、捨てられた目印を調べ直せない。不正確な図を正しいと思って進む方が、図を持っていないと自覚して確かめるより危ういこともある。原本を保つ価値は、今の解釈が見落としたものへ将来も戻れる点にある。一次の地図も地形そのものではなく、本人が後から加えた説明によって初めて読み取れる意図もある。

## 正しさは何との対応か

| 確かめたいこと | 照合するもの |
| --- | --- |
| ある人がどんな表現をしたか | 当時の発言と保存された字句 |
| その人が何を意味したか | 発言が向けられた対象・文脈・意図と、そこから得た解釈 |
| 発言の主張が事実に合うか | 主張の対象となった時点の実態 |
| 今その判断を使えるか | 当時と現在の条件、後の訂正、今の目的と採否 |

作業が完了したとの誤報も、誤報が発せられたという事実については正確に記録できる。その説明を読んだ人の誤解も、元の発言については解釈だが、その人が当時どう理解したかを調べるときには一次の表現になる。

意図への忠実性が基準になるのは、人の発言が何を意味したかを解釈するときである。無人の水位計が午前3時に2メートルを示した場合には、まず機器の出力が正確に残ったかを問い、次にどの基準面から測った値か、実際の水位をどこまで表すかを調べる。その場で設置者が水位を認識している必要はない。欠測欄から、水位ゼロ・観測未実施・記録の欠落のいずれかを決めることもできない。
