# 原本と解釈

## 主体の外に残るもの

主体が対象をどう捉え、何を伝えようとしたかは、その主体の内にある。このように、主体の内で成り立つ意図や認識を仮想として扱う。声として発した言葉も紙に書いた文章も、外から捉えられる実体になる。発した声はその場で消え得る。発言を保存して初めて、発言者も覚えていない言い回しを後から聞き直せる。保存された表現には、言葉を選ぶ時点で明確だったことも、まだ言い分けられなかったこともある。聞き手がそこで意味を捉えると、聞き手の内に解釈が生じる。その解釈を書き残せば、さらに別の表現が外に残る。

記録する必要は、この隔たりと時間の両方から生じる。後日の本人は、忘れたこと、新しく学んだこと、その間に変わった欲求を抱えて当時を振り返る。外に残した表現があれば、今の記憶と別に、当時何と言えたかを確かめられる。書きながら初めて自分の欲求を言い表せたり、読み返して曖昧さに気づいたりもする。主体が変化するために記録が要る一方で、記録を認識し直すことも主体を変える。

## 同じと言える範囲

あることが実際に起きたという事実は、後でその出来事をどう理解したかによって変わらない。ただし、主体が扱えるのは、自分が認識したこと、表現されたもの、そこから読み取ったことだ。原本は、このうち、当時何がどのように表現されたかを確かめ直す基点を与える。

**解釈と原本は別のものである。** 同じ意味を捉えられた場合にも、ある主体の理解が、その主体の読んだ原本そのものになることはない。一字を変えた文章を、元の字句を完全に再現したものとして扱うことはできない。意味がよく通る言い換えでも、この基準に例外は生じない。忠実な複製は字句を完全に保持できるが、複製された媒体と作られた経緯を持つ。同じ文字列か、同じ実体か、同じ意味を伝えているかには、それぞれ異なる答えがあり得る。

発言の意図については、複数の解釈に優劣がある。たとえば相手を批判するために皮肉で褒めたとき、賛辞を文字どおりに受け取ると意図を外す。違う表現で批判の意味を説明した方が、発言者が伝えようとしたことに忠実な場合がある。何について、どのやり取りに応じて発した言葉かが、その判断を支える。短い同意の発言は、一語も欠かさず残しても、同意された案がどれか、どこまでを認めたかによって意味が違う。発言者・相手・対象・時点とその関係も、理解を支える情報である。

真実を地形にたとえると、原本は地形を指し示す地図に当たる。ある発言者がその時に何を伝えようとしたかを知るうえで、実際に発した言葉は、その意図に最も直接につながる地図である。人間同士の発言にも、AIがその場で返した表現にも同じ関係が成り立つ。簡略図は道を探す人を助けるが、作り手の目的に沿って目印を選んでいる。簡略図だけを引き継ぐと、別の人が別の問いを持ったとき、捨てられた目印を調べ直せない。不正確な図を正しいと思って進む方が、図を持っていないと自覚して確かめるより危ういこともある。原本を保つ価値は、今の解釈が見落としたものへ将来も戻れる点にある。一次の地図も地形そのものではなく、本人が後から加えた説明によって初めて読み取れる意図もある。

## 共通の原本と異なる理解

同じ仕様を読んで、一人は起動のたびに検査すると理解し、もう一人は操作のたびに検査すると理解したとする。共通の原本があれば、それぞれがどの言葉を何に結び付けたかについて検討できる。二人に文書が届いたことから、理解が一致したことや、組織として片方の解釈を採用したことまでは導けない。合意が成立したかを知るには、誰がどの立場で何に同意したかが要る。さらに、その合意どおりに検査が実施されたかは、実際の操作と結果に照らして確かめる。

## 正しさは何との対応か

同じ記録でも、問いに応じて何と照合するかが変わる。たとえば、発言を扱う場合には次の区別ができる。

| 確かめたいこと | 照合するもの |
| --- | --- |
| ある人がどんな表現をしたか | 当時の発言と保存された字句 |
| その人が何を意味したか | 発言が向けられた対象・文脈・意図と、そこから得た解釈 |
| 発言の主張が事実に合うか | 主張の対象となった時点の実態 |
| 今その判断を使えるか | 当時と現在の条件、後の訂正、今の目的と採否 |

作業が完了したとの誤報も、誤報が発せられたという事実については正確に記録できる。その説明を誤解した人が自分の理解を書き残せば、その文章は元の発言については解釈だが、その人が当時どう理解したかを調べるときには一次の表現になる。

意図への忠実性が基準になるのは、発言者が何を意味したかを解釈するときである。無人の水位計が午前3時に2メートルを示した場合には、まず機器の出力が正確に残ったかを問い、次にどの基準面から測った値か、実際の水位をどこまで表すかを調べる。その場で設置者が水位を認識している必要はない。欠測欄から、水位ゼロ・観測未実施・記録の欠落のいずれかを決めることもできない。
