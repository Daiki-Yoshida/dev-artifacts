# 第3哲学　記録と真実と伝達の哲学（RTC）

## 思想の中心

昨日ある案に同意した人が、今日も同じ案を支持するとは限らない。昨日の判断を知りたいとき、今日の本人に聞けば、その間に得た知識も、変わった事情も、忘れたことも返答に影響する。当時の発言を記録してあれば、今の説明と突き合わせ、何を補ったのか、どの判断を変えたのかを調べられる。ここに記録の第一の意味がある。主体が変わった後にも、変わる前の表現をもう一度捉えることができる。

表現が残れば意図も真実もそのまま取り出せる、というわけにはいかない。当時の言葉を正しく写せたか、その言葉で伝えようとしたことを汲めたか、語られた出来事が実際に起きたかは、それぞれ確かめ方が違う。今の解釈が誤っていれば後から訂正できる。誤った理解や評価にも、何が当時の判断を導き、何を根拠に改めたのかを伝える価値がある。

**RTC（Record / Truth / Communication）の責務は記録である。** その責務には、当時の表現を保つことと、後の自分や他の主体が必要なときにその意味と根拠を理解し、判断に使えるように伝えることが含まれる。事情を熟知した人にだけ分かる断片では引き継げない。一方、明快な説明を一つ残しても、それに入らなかった条件を後から調べる手掛かりが消えていれば、解釈を再検討できない。保存と伝達を一つの哲学で扱うのはこのためである。

この考えは、立場が変われば同じ人でも欲求や責務の異なる主体になるというSCBの理解を基礎とする。たとえば活動の引継ぎでは、当時の状態や判断をどう後任に伝えるかをRTCが扱い、その状態を現在の環境で維持・再形成できるかをEICが扱う。引き継いだ目的に照らしてどの行為を選び、実際に何が満たされたかはAJFの問いとなる。
