# 第3哲学　記録と真実と伝達の哲学（RTC）

RTC（Record / Truth / Communication）が扱うのは、変化する主体の間で、ある時点の表現や判断をどう残し、そこから何を知り、何を次に伝えられるか、という問いである。自分が今日残した説明も、明日の自分にとっては改めて意味を読み取る対象になる。記録に残るものと、それを使う主体が理解するものとの間に、この哲学の出発点がある。

過去の判断を引き継ぐ場面には、記録と伝達の両方が関わる。文字が残っていても、後の主体が、誰のどの判断を表すのか見分けられなければ、その判断を引き継げない。反対に、筋の通った説明を渡せても、元の表現や当時の条件が失われていれば、誤りに気づいたときに検討をやり直せない。当時の表現を保ち、後の主体がそこに戻って理解・判断に使えるようにするところまでが、RTCの扱う「記録」の責務である。

この責務は、主体・契約・境界を扱うSCBを基礎とする。同じ個人でも立場や時点が変われば、何を求め、どの意味を読み取るかが変わるからである。たとえば引継ぎで、過去の判断がどう伝わったかはRTC、作業に必要な条件が今も整っているかはEIC、次の行為が目的に適い、結果が求めたものを満たしたかはAJFの問いになる。
