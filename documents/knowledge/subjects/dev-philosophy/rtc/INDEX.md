# 第3哲学　記録と真実と伝達の哲学（RTC）

決めた本人がひと月後に同じ議論を読み返すと、当時は当然だと思った条件を忘れていたり、後から判明した事実まで知っていたつもりになったりする。本人が替わらなくても、判断する主体の立場や記憶は変わる。最初の言葉がそのまま残っていれば、現在の説明と突き合わせて、当時の表現と、その後に加わった理解とを辿り分けられる。

SERAの第3哲学、**RTC（Record / Truth / Communication）** が担うのは記録である。現在の理解が及ばなかった部分にも後から戻れるように当時の表現を保つこと、後の自分や他の主体が、その意味と根拠に辿り着き、必要な判断に使えるように伝えることを一体として扱う。ある解釈を訂正するときにも、その結論を今使う人と、なぜ訂正したかを確かめる人とでは必要な説明が異なる。

人の立場・欲求・責務と、その主体が捉えた意味との関係は、主体と契約と境界の哲学（SCB）を基礎とする。活動を引き継ぐとき、以前の条件と判断を次の人に伝えることはRTCが担う。その条件を現在の環境でも整えられるかは環境と独立と制御の哲学（EIC）が、引き継いだ目的を何によって果たし、実際に何を満たしたかは実現と判断と充足の哲学（AJF）が扱う。
