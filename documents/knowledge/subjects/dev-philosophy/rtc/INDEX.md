# 第3哲学　記録と真実と伝達の哲学（RTC）

RTC（Record / Truth / Communication）が扱うのは、変化する主体の間で、ある時点の表現や判断をどう残し、そこから何を知り、何を次に伝えられるか、という問いである。自分が今日残した説明も、明日の自分にとっては改めて意味を読み取る対象になる。記録に残るものと、それを使う主体が理解するものとの間に、この哲学の出発点がある。

SERAで記録と伝達を一つの哲学に含めるのは、記録がいつ価値を発揮するかを考えれば分かる。文字が残っていても、後の主体が、誰のどの判断を表すのか見分けられなければ、その判断を引き継げない。反対に、筋の通った説明を渡せても、元の表現や当時の条件が失われていれば、誤りに気づいたときに検討をやり直せない。どちらまで引き受けるかは、残す目的と伝える相手によって決まる。
