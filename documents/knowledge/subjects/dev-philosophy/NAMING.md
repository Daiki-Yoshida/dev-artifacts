# 体系の名称と番号

「SERA」の一字一字は、各哲学が引き受ける対象の英語名から採った。各哲学の真名も、漢字二文字の語を三つ用い、最初の語にその哲学の対象を置く。残る二語には、その対象を理解するために切り離せない関係を表す語を置いた。この三語という形式を採用した範囲は、SERAの四哲学である。たとえばSCBは四体系の根源に当たるが、「根源」は体系内の役割である。何について考える哲学かを名乗るには、存在を捉え、意味を定める「主体」がふさわしい。

| 現在の番号と略名 | 真名に対応する英語 | SERA採用直前の番号と略名 |
| --- | --- | --- |
| 第一・SCB | Subject / Contract / Boundary | 第一・SCB |
| 第二・EIC | Environment / Independence / Control | 第四・EIC |
| 第三・RTC | Record / Truth / Communication | 第二・RTC |
| 第四・AJF | Actualization / Judgment / Fulfillment | 第三・RJF |

## 何を名前で伝えるか

記録の哲学には、真実を先頭に置くTRCという名称が一度採用された。記録を先頭に移すと、原本の意味を後から読み直すことも、訂正の経緯を後の主体に伝えることも、自分の責務として名指せる。この範囲を示す語としては、書き付ける行為だけを思わせる *Inscription* や、保管に重きを置く *Archive* よりも *Record* が適している。

実現の哲学は、一時「目的と必要と充足」という仮称で、目的に対して必要な範囲を問うところから出発した。その後、何を根拠に行為を選ぶか、どこまで実現できたか、その結果を踏まえてどう判断を更新するかを、一つの責務として扱うようになった。そこで実現を第一語とし、判断と充足を続けた。SERAの総称を定めた際には、この日本語の真名を保ち、第一語に当てる英語を *Realization* から *Actualization* に改めた。主体が選んだ働きかけによって、それまで可能性だったことが現実にどこまで成立したかを問うためである。「判断」と「充足」も名に残ることで、選んだ理由と実際の結果を別々に確かめられる。

SERAは「セラ」と呼べて、呼び名の各文字から主体・環境・記録・実現を順に思い出せる。以前の番号を保って同じ四語を並べるとSRAEとなり、読み方を別に覚える負担が生じる。総称だけをSERAにして番号を据え置く案では、三文字目のRから記録を正しく思い出しても、旧第三哲学の実現を指してしまう。名称が広まった後の改番は、すでに覚え、使い、他の人に伝えた人にも学び直しを求める。このため総称と番号を合わせて採用した。

最初に主体を置くのは、他の三哲学が主体の欲求・契約・境界を前提にするためである。続く三つの順番には、名前から引けるという意味がある。たとえば環境に手を加えるかを考えるときには、第二の環境と第四の実現を同時に使える。改番前の「第三哲学」は実現を指すため、過去の決定の意味を取るときには当時の呼び名で読む。

## 採用の範囲

2026年11月26日に、SERAという総称、四哲学の番号と名称の対応、AJFの英語と略名が採用された。同日、当時の四哲学の本文は、方法論の検討に進むための基準として**仮決定**となった。名称を採用した判断と、その時点の本文に与えた位置づけは区別される。とくに将来の必要が判明する前にどこまで先行実装するかは、方法論に残った問いである。
