# 体系の名前と採用の経緯

SERAの各哲学には、漢字二文字の語を三つ並べた真名がある。第一語でその哲学が何を引き受けるかを示し、続く二語で、その対象を考えるうえで切り離せない関係を表す。たとえば「主体と契約と境界」は、存在を一つのまとまりと捉えたのは誰か、その主体にとって何を担うか、どこまでをその意味に含めるかを一緒に名指す。三語という形式を選んだのは、この四体系についてである。

| 現在の番号 | 真名 | 三語に対応する英語 | 略名 |
| --- | --- | --- | --- |
| 第一 | 主体と契約と境界の哲学 | Subject / Contract / Boundary | SCB |
| 第二 | 環境と独立と制御の哲学 | Environment / Independence / Control | EIC |
| 第三 | 記録と真実と伝達の哲学 | Record / Truth / Communication | RTC |
| 第四 | 実現と判断と充足の哲学 | Actualization / Judgment / Fulfillment | AJF |

## 四体系の境界を決めるまで

最初に一つの体系として論じていたのは、まとまりの命名、主体の欲求、契約と境界をめぐる考えだった。必要な範囲を定める原則、記録、環境の清潔さにはこれとは異なる問いがあり、契約と境界の体系を先に掘り下げた。この成立順と、いま個々の開発でどの哲学から用いるかは別のことである。

2026年11月20日、開発哲学を四つの責務に分けた。当初の「契約と境界」には、その意味を定める「主体」を加えた。「真実と記録」と「理解と伝達」は、過去の表現を後の主体の理解につなげる責務として一つにまとめた。広い候補だった「目的と実現」は、何が必要で何が満たされたかを扱う「目的と必要と充足」に絞った。環境にまつわる手順・清潔さ・安全性・再現性の候補には、活動条件を成り立たせ、作用を制御し、状態を再形成するという共通点から「状態と制御と再現」を置いた。後二者は引き続き検討する仮称だった。

11月22日に真名と略名を確定したのは、当時の第一「主体と契約と境界（SCB）」と第二「真実と記録と伝達（TRC）」の二つである。当時の第三に対応するPNF、第四に対応するSCRも略名案に挙がったが、この日に採用した名称の範囲には入らない。

## 責務を表す語が定まるまで

**11月24日、主体と記録。** SCBを「根源の哲学」と呼べば、すべての思考の基礎を担う位置づけは伝わる。一方、誰の欲求から存在に意味が与えられるかという対象が名前から消えてしまう。そこで責務を「主体」、体系の中で果たす役割を「根源」と捉え、SCBの名を維持した。記録については、真実に迫るための探索にも、当時の判断を後任に渡すことにも、原本を保持して理解に結び付けるという責務がある。その責務を第一語に出して「記録と真実と伝達（RTC）」に改めた。

**同日、環境。** 状態の維持や再形成を何のために行うかをたどると、一つの主体の活動を支える環境に行き着く。そこで第一語を「環境」とし、その環境がどこまで自らの責務を担えるかを「独立」で表した。第三語には再現・履行・運用などが候補に上がった。「環境と独立と再現（EIR）」なら、失われた条件の再形成を前面に出せる。「環境と独立と制御（EIC）」なら、使用中の状態を保ち、操作の作用先を限定し、必要な条件を作り直すことまで扱える。この時点でEICを採用した。EIRは検討時の候補であり、改称前に採用済みだった略名ではない。

**11月25日、実現。** 当時の第三には、主体の「判断と実現」を暫定の責務範囲として置いた。この段階では一語の呼称、真名、略名は保留だった。あらゆる判断を第三に集めれば、存在を定義する判断や記録を解釈する判断まで含んでしまう。第三が扱う範囲を決めるのは、その主体が自らの働きかけで何を実現しようとしているかである。そこで一語での呼称を「実現」とし、手段を選ぶときにも結果を受けて見直すときにも働く「判断」を裏面に置いた。最後に、誰のどの必要が実際に満たされたかを表す「充足」を名に含め、「実現と判断と充足（Realization / Judgment / Fulfillment、RJF）」を採用した。必要な範囲を見定めるAONはこの体系の一原則である。

## 総称と番号をそろえた理由

11月26日に四体系をひとまとめに呼ぶ名前を選んだ。各体系の責務を頭文字から思い出せて、会話でもひと息で呼べることが、総称に求めた働きである。主体・記録・実現・環境という当時の順序を保つ案の一つにSIREがあった。記録に *Inscription* を当てると書き付ける行為に意味が偏り、*Archive* を当てると保管が前に出る。どちらも、過去の表現に立ち戻り、訂正の意味を将来の主体に伝える働きまでは名指しにくい。責務を表す英語には *Record* を保った。これは、二日前に「記録」を真名の第一語に移した後、総称を選ぶ場面で行った比較である。

実現には *Actualization* を選んだ。主体の関わりによって、可能だったことがどこまで現実になったかを表せる語である。RJFの日本語名と責務を引き継ぎ、英語の第一語に合わせて略名をAJFに改めた。その四語を旧番号で並べたSRAEより、SERAなら「セラ」と呼びやすく、主体を先頭に保てる。

総称だけをSERAとして番号を据え置く案もあった。それでは三文字目のRから記録を正しく思い出しても、「第三哲学」は実現を指すことになる。名前が普及してから番号を変えると、その名を学んだ人や、その番号で交わした説明にも変更が及ぶ。総称と同時に番号をそろえ、名前の読み順から四体系を引けるようにした。

| 責務 | 総称の採用直前 | SERA採用後 |
| --- | --- | --- |
| 主体 | 第一・SCB | 第一・SCB |
| 環境 | 第四・EIC | 第二・EIC |
| 記録 | 第二・RTC | 第三・RTC |
| 実現 | 第三・RJF | 第四・AJF |

このため「第三哲学」という語は、それが使われた時点によって対象が変わる。SCBには、残る三体系が前提とする主体・契約・境界の意味を定めるという、第一に置く理由がある。続くE・R・Aの順には、総称を覚えれば番号と責務を一緒に思い出せるという役割がある。

11月26日に採用した総称・番号・真名と略名の対応は確定している。同日、当時の四哲学の本文は、これを基礎に開発方法論の検討へ進むための**仮決定**となった。将来必要になるか分からない機能をどこまで先に設計し、いつ実装するかという具体的な判断は、方法論で検討する問いとして残った。
