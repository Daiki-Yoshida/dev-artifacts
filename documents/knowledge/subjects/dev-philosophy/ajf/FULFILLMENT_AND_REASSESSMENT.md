# 充足と判断の更新

## 満たされたことと、主体が実現したこと

充足とは、ある主体の目的と責務に照らして、必要としていたことが現実に満たされていることである。評価するには、誰の何が、どの範囲で満たされたのかを特定する。その結果を特定の人が実現したと捉えるなら、さらに、その人が選んだ関わり方が結果の成立にどう働いたのかを問う。

暗い広場でたまたま車が通り、その前照灯で時計を読めたとする。通行人がその瞬間の時刻を知るという欲求はかなった。時計が通行人から見える位置にあったからこそ読めたのなら、設置場所を選んだ人の寄与もある。しかし、その一回から、設置者が夜間を通じて時刻の読める広場を実現したとは判断できない。反対に、必要な時間帯の明るさを調べて照明を選んでも、当日の故障で読めなくなることはある。判断に理由があったこと、望んだ結果が現れたこと、その結果を自分の働きが支えたことは、それぞれ別に確かめられる。

時計が約束どおり正しい時刻を示していても、暗がりの利用者からは読めないかもしれない。時計を作った人の契約の履行と、利用者の目的の充足では、確かめる対象が異なる。また、日没直後に表示を読めたという観察は、その時点の読み取りを裏づける。ほかに根拠がなければ、深夜も読めたとも、深夜は読めなかったとも断定できない。まだ確かめられない部分があることは、それ自体では実態に不足があった証拠にならない。

## 部分を果たしても全体が実現しない場合

一つの責務を分けるとき、部分を合わせた結果が上位の責務を満たすには、部分同士を結ぶ条件も足りていなければならない。二本の列車を乗り継いで約束の時刻までに到着する旅なら、それぞれの列車に間に合うことに加え、最初の列車を降りてから次の乗り場へ移る時間が要る。列車が二本とも時刻どおりに走っても、接続に間に合わなければ、乗客の目的は果たせない。

接続に失敗した後、誰が次の判断を引き受けるかも、各自がどの範囲を担ったかによる。旅行会社が到着までを含む旅程を引き受けたなら、全体について判断する責務は旅行会社に残る。乗客が二枚の切符を別々に買って行程を組み、各社が一区間の運行だけを約束したなら、次の便を探す理由は乗客自身の目的にある。複数の主体が共同で接続を引き受けていれば、それぞれに残る判断はその合意によって決まる。

予定時刻を過ぎた後も、乗客に到着したいという欲求が残っていれば、別便を手配する意味はある。実際に別便で着けば、その時点の欲求は満たされる。間に合わなかった旅を遡って達成済みと扱うと、次に改善すべき接続条件が見えなくなる。

## 何を振り返り、何を更新するか

当時、なぜそのように決めたのかを捉えるには、主体がその時点で知っていたことを手掛かりにする。後で事情を知れば、そのとき選べた別の手段や、調べれば気づけた見落としも分かる。たとえば、通行止めの掲示を読んでいない人が別の理由で迂回し、通行止めを避けられたとする。掲示は当時確かめ得た情報でも、それが迂回を選んだ理由ではない。掲示を確かめるべきだったかは、その人が安全の確認まで引き受けていたかによる。結果がよかった場合にも、その選び方を吟味する理由は残る。

広場の時計が今は夜に読めないと分かった場合も、何が変わったのかによって、次の判断は変わる。

| 経緯 | 見直すもの |
| --- | --- |
| 初めから夜の利用が必要だったのに、設置時にその時間帯の明るさを考慮しなかった。 | 当時求められていた条件と、自分が選んだ手段を照合する。もとの責務を果たすために不足したものに対処する。 |
| 初めは読めていたが、街灯が早く消えるようになった。 | 今も同じ時間帯の利用を引き受けているなら、変わった照明条件のもとでそれを支える方法を選び直す。 |
| 設置後に初めて夜も広場を使うことになった。 | 新しく生じた欲求を誰がどこまで引き受けるかを決める。それによって過去の設置が当時の契約に反していたことにはならない。 |

以前の判断を後任が理解するために何を残し、どう伝えるかはRTCが扱う。実際の照明や電源をどう利用し、変化した環境をどう整え直すかはEICが扱う。それらを踏まえ、当時何が満たされ、今も続く責務と新たな欲求に対してどの行為を選ぶ理由があるかを問うのがAJFである。
