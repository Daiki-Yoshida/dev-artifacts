# 第4哲学　実現と判断と充足の哲学（AJF）

夜も広場から時刻を知りたい。その願いに応えて管理者が時計を設けたとする。では、暗くなった後、そこを通った人は本当に時刻を知ることができたか。設置した人の行為は、どこまでその結果を支えたか。AJFは、主体が何を成り立たせようとしたかを出発点に、目的に向けた選択と、現実に生じた結果との関係を扱う。

| 章 | 問い |
| --- | --- |
| [1．意思と判断](WILL_AND_JUDGMENT.md) | 誰が何を求め、どう関わることを選んだのか。その選択にはどんな理由があったのか。 |
| [2．必要と選択](NECESSITY_AND_CHOICE.md) | 目的に欠かせないものはどれか。手段を加えるときと、すでにある手段を外すときでは、何を確かめる必要があるか。 |
| [3．充足と判断の更新](FULFILLMENT_AND_REASSESSMENT.md) | 誰のどの必要が満たされ、誰の選択がそこに寄与したのか。事情が変わってもなお引き受けていることは何か。 |

一語で表す責務は「実現」である。日本語の真名に対応する英語は *Actualization / Judgment / Fulfillment*。この三語のうち「判断」は、行為を選ぶときにも結果を評価するときにも働く。「充足」は、理由をもって選んだだけで終わらせず、求めたものが実際にどこまでかなったかを問う語である。真名を定めた当初は第三哲学で、実現に *Realization* を当ててRJFと呼んだ。四哲学の名と番号をSERAの順に整えた現在は、実現を受け持つ第四哲学がAJFである。
