# 第2哲学　環境と独立と制御の哲学（EIC）

EICは、主体の活動を支える環境を扱う。主体が何のために何を環境と捉えたかによって、その環境の責務と境界が定まる。独立・清潔さ・制御・安全性・再現性は、それぞれ別個に環境へ課す目標ではなく、その境界で何を引き受け、実際にどのような状態や作用を保つ必要があるかから導かれる。ここでは、主体が定めたまとまりに契約と境界があるというSCBの考え方を、活動の基盤に適用する。

## 名称と位置づけ

EICは Environment、Independence、Control の頭文字である。当初は第四哲学として状態・制御・再現を検討し、やがて責務の対象が活動の環境に定まった。名称の第三語には、環境を再び整える「再現」、境界で約束を果たす「履行」、環境を通じて活動する「運用」も挙がり、「制御」と「再現」の両方を掲げる案もあった。採用した「制御」は、環境の状態と作用を、主体が引き受けた責務の範囲に対応させる意味を持つ。再現性もEICに含まれ、名称の決定によって各性質の優先順位までが定まったわけではない。

四つの哲学をSERAと総称して番号を整えたとき、環境を扱うEICは第二哲学となった。真名・略名・責務範囲は確定し、四哲学の本文は2026年11月26日に、方法論の検討へ進むための仮決定版となった。
