# 第2哲学　環境と独立と制御の哲学（EIC）

陶工が器の制作を続けるとき、粘土の湿り具合や道具の状態によって次にできる仕事が変わる。陶工はそれらを確かめ、利用し、ときには自分で整える。EICが扱うのは、このように主体が自分の活動の基盤として捉える環境である。

SERAの第一哲学（SCB）は、主体が欲求に応じて一つのまとまりを定め、そこに責務と境界が生まれる関係を扱う。EICはこの関係を環境に適用する。誰のどの活動を支える環境かによって、自分で維持する範囲、外部へ委ねる責務、制御すべき作用が決まる。環境を実現する具体的な方法は、その条件に応じて選べる。

## 名称と位置づけ

真名の三語は Environment、Independence、Control に対応する。検討の初期には第四哲学として、活動の状態・制御・再現を中心に捉えていた。責務を環境に定めた後も、環境を再形成することに着目した「再現」、契約を果たすことに着目した「履行」、環境を通じた活動に着目した「運用」が第三語の候補に挙がった。「制御」と「再現」をともに残す四語の案もあった。採用された「制御」は、環境を通じてどんな行為ができるか、その作用を境界でどう約束どおりに保つかまでを扱う。再現も引き続きこの哲学に属する。第三語を選んだ時点で、再現と他の性質の優先順位までが定まったわけではない。

SERAの総称と番号を採用した際に、環境は第二哲学となった。真名・略名・責務範囲は確定し、2026年11月26日には四哲学の本文が方法論を検討するための仮決定版となった。
