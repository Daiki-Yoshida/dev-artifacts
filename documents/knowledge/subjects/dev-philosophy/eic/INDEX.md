# 第2哲学　環境と独立と制御の哲学（EIC）

橋を造るには、橋そのものの設計に加え、それを造れる現場が要る。同じ重機が置かれていても、地盤がその重量を支えるか、必要な日に機体を借りられるか、誰に操作の権限があるかで、そこで成し遂げられることは変わる。工事で地盤や搬入路を整えれば、現場は活動を通じても変わる。

**EIC（Environment / Independence / Control）**は、この活動の基盤をどう定め、引き受けた責務をそこで実際に果たせるようにするかを扱う。「主体・契約・境界」の考え方を環境に適用すると、独立とは誰からも何も借りずに済むことか、他の作業に影響がなければ何をしても清潔といえるか、といった問いに、具体的な契約に立って答えられる。対象は、建物や機器を作る活動にも、組織・規則・アルゴリズムを作る活動にも及ぶ。
