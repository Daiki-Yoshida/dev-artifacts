# 環境の独立と依存

## 独立の基準となる主体と契約

環境の独立は、ある主体がその環境に求めた責務と境界に即して定まる。一つのまとまりを定義すれば、そこで引き受ける責務を他のまとまりの責務から区別できる。その独立が実態でも保たれるのは、他との間で契約を果たしながら、各々が自分の内側を扱う自由を保てるときである。

外部の設備を借りても、自分の環境が独立した責務を担うことはできる。どの程度の自律性や継続性が要るかは、その環境を何のために成立させるかにかかっている。自前の設備が多いことも、依存先が少ないことも、それだけで独立を意味しない。

## 管理するものと依存するもの

自ら引き受けた資源や状態は、その責務に見合う範囲で実際に維持・変更できるようにする。外部に依存する部分については、何のためにどの条件を要し、そのうち何を相手が引き受けたかを区別する。建設に適した天候が必要でも、天候を誰かが約束したことにはならない。機械を借りる場合には、使用できる期間や能力は相手との契約になり得るが、実際にその日に動くかは履行の問題である。

利用側は必要な条件と依存先との取り決めを扱い、その取り決めに指定のない保守方法は、貸主が自分の責務と実現可能性に即して選べる。この区別があるため、利用側が相手の設備を丸ごと管理しなくても、双方とも固有の責務を負える。

## 依存先や目的が変わったとき

同じ設備を使う場合にも、一日限りの試験と数年続く生産では、必要な利用期間も、提供が終わったときに代替が要るかも違う。設備を使い続けられなくなったという結果だけでは、見直すべき契約は決められない。

| 起きたこと | 問題になる関係 |
| --- | --- |
| 貸主が約束した期間の途中で提供を止めた | 必要な期間について合意はあった。依存先による契約の履行が問題になる。 |
| 初めから長期利用が必要だったが、一日だけ借りる契約をした | 貸主が約束を守っても環境の条件が足りない。依存関係の定め方が当初の目的に合っていなかった。 |
| 一日の試験を終えた後、継続して生産することにした | 当初の環境は目的を果たし得た。これから必要になる期間と条件について契約を定め直す。 |
