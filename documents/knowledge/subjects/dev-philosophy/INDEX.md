# 開発哲学

SERA（セラ）は、主体・環境・記録・実現を扱う四つの開発哲学の総称である。道具を作る人も、共同で使う制度を設計する人も、誰のために何を成り立たせるかを決め、それに応じた働きかけを選ぶ。既にあるものに新しい使い方を見いだすときにも、この問いがある。

| 番号 | 哲学 | ここで扱う問い |
| --- | --- | --- |
| 第一・S | [主体と契約と境界（SCB）](scb/INDEX.md) | 主体は何を求めて一つの存在を名指すのか。その意味は、誰とのどの関係で責務になるのか。 |
| 第二・E | [環境と独立と制御（EIC）](eic/INDEX.md) | 活動はどんな条件や関係に支えられているか。そのうち何を自分で整え、何を他に委ねるか。 |
| 第三・R | [記録と真実と伝達（RTC）](rtc/INDEX.md) | 表現を残すと何を確かめ直せるか。その意味や判断の根拠を、後の自分や別の主体にどう渡せるか。 |
| 第四・A | [実現と判断と充足（AJF）](ajf/INDEX.md) | 誰が何を実現しようとして関わり、その結果、どの必要がどこまで満たされたか。 |

[四体系の責務とその関係](SERA.md)では、陶工の仕事を途中から引き継ぐ場合と、匿名投票を設計する場合を通じて、一つの開発で四つの問いがどう関わるかを扱う。[体系の名前と採用の経緯](NAMING.md)には、真名・略名が指す意味、それぞれの採用時点、番号との対応をまとめた。
