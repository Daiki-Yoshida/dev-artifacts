# 開発哲学

## SERA開発哲学

**SERA（セラ）**は、主体が何を成り立たせようとしているかを起点に、その活動を支える環境、意味を伝える記録、望んだことの実現を考える四つの哲学の総称である。物を作るときにも、人が共同で使う制度を設けるときにも、同じ問いを使える。ここでいう普遍性は、主体が何かを意味のあるまとまりとして見いだし、定義し、成立させる営みに共通するという意味である。たとえば風を受けて進む帆を開発するとき、風そのものが吹く物理的な理由はこの哲学の射程の外にある。

| 番号 | 哲学 | その哲学が扱う問い |
| --- | --- | --- |
| 第一・S | [主体と契約と境界の哲学（SCB）](scb/INDEX.md) | 誰のどんな欲求から、何を一つのまとまりと捉え、どこまでをその責務と定めたのか。 |
| 第二・E | [環境と独立と制御の哲学（EIC）](eic/INDEX.md) | その活動は何に依存し、どの条件を自ら整えられるか。働きかけたとき、影響はどこに及ぶか。 |
| 第三・R | [記録と真実と伝達の哲学（RTC）](rtc/INDEX.md) | 何が捉えられ、どんな表現として残ったか。後の主体はそこから何を知り、何を判断できるか。 |
| 第四・A | [実現と判断と充足の哲学（AJF）](ajf/INDEX.md) | 何を実現しようと、どんな働きかけを選んだか。その結果、誰のどの必要が満たされたか。 |

[四哲学を組み合わせて考える](SERA.md)では、全員が同じ案に投じた匿名投票を例に、四つの問いが同じ事象の違う側面をどう明らかにするかを扱う。[体系の名称と番号](NAMING.md)には、各名が表す責務、改称・改番の理由、仮決定の範囲をまとめている。
