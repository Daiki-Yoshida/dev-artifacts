# subjects を作る手順

1. **主題と問いを定める。** [subjects の定義と構成](../models/SUBJECT_MODEL.md)に従い、対象の哲学・方法論が何を扱うのかを確かめる。ファイルは、その対象について続けて理解する必要がある内容ごとに分ける。
2. **新形式の原記録で意味を確かめる。** 初出の発言から、反論・具体例・訂正・採否が示されたところまで追う。旧草案が実際に使った原記録の実体が旧形式にしかない場合に限り、その原記録を[原記録を追加する手順](RECORD_INTAKE.md)に従って新形式に取り込む。旧草案の本文は使わない。
3. **主題として書く。** 複数の発言に分かれた定義・理由・条件を、概念間の関係が分かる文章に組み立てる。具体例は、それが何を説明し、条件を変えると結論がどう変わるのかと一緒に記す。過去の案を扱うときは、どこが受け継がれ、どこが訂正されたかを区別する。索引には本文の扱う問いと配置を示す。
4. **意味と使い道を両側から検証する。** まず本文を読み、原記録を開き直さずに主題の問いに答えられるか、読者に発言の再解釈を委ねていないかを確かめる。次に原記録へ戻り、必要な主張や例外の抜け、断定の強まり、訂正前後の混同を確かめる。議論で条件を変えると結論が変わった事例は、本文からもその違いを説明できるか試す。最後に、索引が現物に対応し、本文に原記録への参照や引用が入り込んでいないことを確かめる。
