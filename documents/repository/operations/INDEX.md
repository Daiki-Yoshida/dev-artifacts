# Repository Operations

`documents/repository/operations/` は、[models](../models/INDEX.md) が所有する管理契約を前提に、リポジトリ固有の実施手順・検証を所有する。

- [Knowledge Update Workflow](KNOWLEDGE_UPDATE_WORKFLOW.md)：source eventの取り込み、Owner承認の扱い、Stage境界、変更管理。
- [Stage 2 Workflow](STAGE2_WORKFLOW.md)：Ownerが採用した哲学先行 A→B→C→D の進め方。
- [Stage 2全件監査・Owner吟味への引継ぎ](stage2/A1_A2_COMPLETION_REPORT.md)：A-1旧subjects70件、A-2 records206件の一次意味監査を完了。監査時点の17件は吟味前の候補。
- [Stage 2の哲学・草案・調査資料](stage2/INDEX.md)：四つの責務（主体・記録・実現・環境）、各体系の名称、編集用草案、出典・判断系譜、一次監査の台帳への入口。
- Artifact射影・配布手順はStage 3で制定する。旧Artifact v2の運用を暗黙に再採用しない。
- 過去の移行・監査・Agentテスト資料は[legacy](../legacy/INDEX.md)に保存する。

ここでモデルの意味を別個に定義しない。
