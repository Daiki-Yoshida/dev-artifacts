# 第3哲学　実現の哲学 — 編集用草案

**責務は実現。実現を表、判断を裏とする。** 「実現の哲学」は責務を一語で示す呼称であり、真名の第一語にも「実現」を置く。残る構成語と略名は検討中である。[呼称と草案整理の採用記録](../../../knowledge/records/2026-11-25-third-philosophy-realization-primary/RECORD.md)

**第3哲学は、主体が、自らの欲求と引き受けた責務に照らして行為を選び、その働きかけが求めた意味をどこまで満たしたかを捉える営みを扱う。**

SCBでは、「時刻を知りたい」という欲求と「時刻が分かるもの」という時計の本質は、同じ意味を主体とまとまりの両側から述べたものである。時計の本質が定まっているときにも、目の前の人が今の時刻を知るにはどうすればよいかという問いが残る。その人は腕時計を見ることも、人に尋ねることもできる。何を根拠にそう関わり、それで実際に時刻を知れたのか。第3哲学は、この選択とその働きの両方を扱う。[SCBの欲求と責務](A3_PHILOSOPHY_DRAFT.md#d2-2)

時計を何と捉えるかにも、記録をどう解釈するかにも判断は働く。本体系に属する判断の範囲は、「この主体は何を実現しようとしているのか」によって定まる。実現を表に置くのは、それが体系の扱う対象を示すからである。判断を裏に置くのは、主体が何に基づいてその実現に関わったかを、行為を選ぶときにも結果を受け取るときにも問うからである。

<a id="will-and-judgment"></a>
## 1．意思と判断

欲求は、主体がある存在に何を求めるかを表す。その求める意味を自らの営みで満たそうとするとき、それが目的となる。**意思は、その目的に向けて自分がどう関わろうとするかに現れる。判断は、何を根拠にその関わり方を選び、その結果をどう受け止めるかに現れる。**

主体には、自ら手を加える、他の主体に委ねる、必要がすでに満たされているので手を加えずにおく、という選択があり得る。何を大切にしているかは、いくつかの欲求のうちどれを今回の目的として引き受けるかにも、その目的を満たす複数の手段からどれを選ぶかにも表れる。委ねた責務については、その責務を担う主体にも判断がある。[SCBの責務の内包・分割・委譲](A3_PHILOSOPHY_DRAFT.md#d2-3)

行為に求める必然性は、その主体が、その状況で、なぜそうするのかという理由があることにある。同じ目的に対して理由のある選択が複数成り立つことも、結果に偶然が作用することもある。先を見通しきれない状況でも、当時知り得た事情に照らして選んだことには、その主体の意思がある。

<a id="purpose-and-responsibility"></a>
## 2．必要と選択

「夜にも広場から時刻を読めるようにしたい」とする。この目的にとって必要なのは、暗くなっても広場から表示を読み取れることである。時計に照明を組み込むのは一つの手段であり、すでに街灯で十分に読める場所に時計を設ける選択もある。方式まで契約で定めた場合には、その方式を用いることも引き受けた責務となる。何が必要で、どこに選択の自由があるかは、誰のどの目的と契約を基準にしているかで変わる。[SCBの内部自由の契約相対性](A3_PHILOSOPHY_DRAFT.md#d3-4)

<a id="aon"></a>
### AONの原則

> **AON — All and Only Necessary**
>
> 必要なものはすべて。必要なものだけ。
>
> 目的と責務に照らして必要なものを、実現の困難さや時期を理由に省略してはならない。
>
> 同時に、必要でないものを、可能性や容易さだけを理由に追加してはならない。
>
> 必要性の判断と、実現方法・費用・実施順序の判断を混同しない。

「すべて」と「だけ」は、同じ目的と責務に照らして判断する。必要な範囲には、表に現れる成果と、それを成り立たせる条件や保証が含まれる。たとえば夜間の読み取りを継続して引き受けるなら、頼りにした街灯が必要な時間帯に点灯することも判断の対象になる。[AONの採用原文（U3）](../../../knowledge/records/2026-11-11-aon-principle-adoption-philosophy-baseline/USER_MESSAGES.md)

<a id="means-and-feasibility"></a>
### 実現手段と必要な時期

ある手段に必要な条件が欠けていれば、求めた意味を満たす別の手段を選べる。費用・困難さ・実施順序は、使える手段と進め方を判断する材料となる。夜間対応を後日に回すなら、それまでの間、夜にも時刻を読めるという必要は未充足のまま残る。期限や予算の上限を目的・契約に含めた場合は、その条件も充足の対象となる。

事情に応じて目的そのものを見直すこともある。そのときは、何を必要としていたのか、これから何を引き受けるのかを区別する。すでに別の主体と契約している内容に変更が及ぶ場合は、その変更がどの合意に支えられるかを扱う。[SCBの契約の成立](A3_PHILOSOPHY_DRAFT.md#d3-2)

<a id="fulfilment"></a>
## 3．充足と判断の更新

**充足とは、目的と責務に照らして必要とされた意味が、実際に満たされていることである。** 「望んだことが起きた」と「主体がそれを実現した」では、後者に、その主体の働きかけが結果にどう結びついたかという問いが加わる。通りがかった車の灯りで時計を一度だけ読めたなら、その人がそのとき時刻を知れたことは事実である。広場を整えた主体が夜にも時刻を読めるようにしたと言えるかは、その主体が選んだ配置や照明が、夜間の読み取りを実際に可能にしているかによる。

時計が合意どおり正確な時刻を表示しているかと、広場にいる人が夜もそれを読めるかには、それぞれ確かめる対象がある。何の契約が履行されたか、誰の欲求がどこまで満たされたかを、その関係に即して捉える。実態が契約に対応していることと、主体がそう判断したことも区別する。何をしたか、何を観察できたか、それがどの充足を裏づけるかを結びつければ、確かめられた範囲と、判断を保留する範囲が分かる。[SCBの契約の履行](A3_PHILOSOPHY_DRAFT.md#d3-3)

<a id="change-and-continuity"></a>
### 当時の判断と、その後に分かったこと

選択にどの根拠があったかは、その主体が当時知り得た事情に照らして捉える。実際に何が満たされたかは、起きた結果に照らして捉える。理由のある試みが目的に届かない場合も、幸運に助けられた選択を見直す理由がある場合もある。

「夜は読めない」と分かったとき、夜間の読み取りが当初から必要だったなら、見落としていた条件に立ち返る。街灯の消灯時刻が変わったなら、新しい実態に対して同じ責務をどう果たすかを考える。広場を夜に使い始めたのが後からなら、新たな欲求に照らして目的や契約を捉え直す。どの時点の誰の欲求・責務に応えるかによって、更新する判断は変わる。[SCBの乖離と再定義](A3_PHILOSOPHY_DRAFT.md#chapter-6)

判断の根拠と経過を後の主体にも辿れるようにする責務は[記録の哲学（RTC）](A3_TRUTH_SOURCE_DRAFT.md)が、活動の基盤となる状態・依存・作用を扱う責務は[環境の哲学（EIC）](A3_STATE_CONTROL_DRAFT.md)が担う。本体系では、それらを踏まえて、求めた意味のどこまでが満たされ、次にどう関わる理由があるかを問う。
