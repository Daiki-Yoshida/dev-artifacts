# 目的と必要と充足の哲学〈仮称〉 — 編集用草案

**状態：第3哲学の編集用草案（Stage 2-A-3）。名称は仮称であり、責務範囲・本質・中心的概念は検討中。** 現時点の草案では、目的と責務に照らした必要性、必要を過不足なく満たすための実現の選択と評価を扱う。必要性を実現する側の都合で変質させず、充足に即して判断する関係を検討する。採用済みの原則AONを本体系に含む。

仮称の「目的」「必要」「充足」は、現時点の草案で扱う関係を表す。目的と責務が必要性の基準となり、その必要が満たされることによって実現を評価する。三語を三つの独立した原則や固定された作業工程として扱う構成ではない。

主体・欲求・責務・契約の定義は[主体と契約と境界の哲学（SCB哲学）](A3_PHILOSOPHY_DRAFT.md)を基礎とする。判断の根拠と経過を後の主体へ伝えることは[記録と真実と伝達の哲学（RTC哲学）](A3_TRUTH_SOURCE_DRAFT.md)、活動の成立条件・状態・作用を把握し再形成することは[状態と制御と再現の哲学〈仮称〉](A3_STATE_CONTROL_DRAFT.md)が担う。本体系はそれぞれの対象や責務を参照し、何が必要で、何をもって満たされたと判断するかを扱う。

名称の現在の扱いは[2026-11-24の名称・責務範囲の採用判断](../../../knowledge/records/2026-11-24-scb-rtc-naming-and-responsibility/RECORD.md)、責務境界の構成判断は[2026-11-20の採用記録](../../../knowledge/records/2026-11-20-four-philosophy-systems-adoption/RECORD.md)を参照する。第3哲学におけるAONの位置づけは[2026-11-24の位置づけの訂正](../../../knowledge/records/2026-11-24-third-philosophy-aon-position-correction/RECORD.md)を参照する。既に採用されたAON本文と説明上の補筆の区別は[レビュー・出典資料](A3_PURPOSE_NECESSITY_REVIEW.md)、四体系全体の関係は[体系の定義](A3_PHILOSOPHY_SYSTEMS.md)に置く。

<a id="purpose-and-responsibility"></a>
## 1．目的と責務に照らして必要を捉える

必要性は、主体が何を求め、どの責務を引き受けているかとの関係において判断する。ある活動に何が必要かを問うときには、その活動をどのような意味のまとまりとして捉え、何を成立させようとしているかを捉える。

同じものでも、主体や目的が変われば必要性は変わり得る。ある活動では成果そのものとなるものが、別の活動では成果を支える手段となることもある。どちらとして扱うかは、その活動における定義と責務による。特定の道具、内部構造、既存のやり方が必要かどうかも、その位置づけに照らして判断する。

目的と責務の捉え方には、主体の認識とコンテキストが関わる。その時点でどの意味を引き受けているかを明らかにし、判断の基準とする。理解の不足や乖離が判明したときには、[主体と契約と境界の哲学の再定義](A3_PHILOSOPHY_DRAFT.md#chapter-6)を踏まえて、必要な範囲から捉え直す。

必要なものには、活動が表向きの成果として生み出すものに加えて、その責務を成立させる条件や保証も含まれる。たとえば、他者のデータを保護する責務を引き受けている活動では、その保護を成立させる仕組みや操作上の条件も必要性の判断対象となる。成果の見た目に現れるかどうかだけで、必要な責務の範囲は決まらない。

一方で、関連し得るものすべてが、現在の目的と責務に必要であるとは限らない。必要性を説明するには、採用しようとするものと、引き受けた意味との関係を示す必要がある。

<a id="aon"></a>
## 2．AON — All and Only Necessary

本体系に含まれる採用済み原則として、Ownerが定めた次の原則を保持する。

> **AON — All and Only Necessary**
>
> 必要なものはすべて。必要なものだけ。
>
> 目的と責務に照らして必要なものを、実現の困難さや時期を理由に省略してはならない。
>
> 同時に、必要でないものを、可能性や容易さだけを理由に追加してはならない。
>
> 必要性の判断と、実現方法・費用・実施順序の判断を混同しない。

採用された本文の一次証拠は、[AON採用時のOwner発言U3](../../../knowledge/records/2026-11-11-aon-principle-adoption-philosophy-baseline/USER_MESSAGES.md)にある。

必要なものをすべて満たすことと、必要なものだけを採用することは、同じ必要性の判断に結びついている。必要な責務を省いて容易な実現へ縮めることも、作れるものを増やして目的の範囲を広げることも、この判断を変質させる。

「すべて」が向かうのは、目的と責務に照らして必要な範囲である。「だけ」が向かうのも、その同じ範囲である。実装量、機能数、制約の数、作業量の大小が、そのまま充足の尺度になるわけではない。小さな実現でも必要な意味が欠けていれば不足し、大きな実現でも必要性に根拠のない追加があれば、その追加を正当化できない。

必要な責務を確実に果たすために内部を整えることも、手段を増やすこともあり得る。採用の根拠は、追加の量や見栄えではなく、それが必要な意味をどう成立させるかにある。

<a id="means-and-feasibility"></a>
## 3．必要性と実現の判断を関係づける

必要性の判断と、実現方法、費用、利用できる条件、実施順序の判断を、それぞれの対象を明らかにして関係づける。実現方法を検討する中で条件が分かり、目的や責務の捉え方を再検討することもある。

ある手段に必要な条件が欠けているとき、その手段の選択や成立可能性を検討する。必要な意味を保った別の手段があるなら、それを選べる。たとえば、同じ保証を異なる構造で実現できる場合、その構造の一つを維持すること自体が責務に含まれているかどうかによって、選択の自由は変わる。[契約と内部自由](A3_PHILOSOPHY_DRAFT.md#chapter-3)の関係が、この判断の基礎になる。

費用や困難さは、実現方法を比較し、利用できる資源や進め方を捉えるための情報となる。必要だと判断したものが高コストであることと、その必要がなくなることは別の事柄である。同様に、容易に追加できることだけでは、追加の必要性は成立しない。

実施順序を決める場合にも、何が必要で、何が既に満たされ、何が残っているかを保つ。必要な状態がいつ成立していなければならないかも、目的と責務に照らして扱う。着手や実現の時点と、必要性の判断との対応を明らかにすることで、未充足の範囲を保ったまま段階の途中を扱える。必要なものを後続の実施対象として保持することと、必要な範囲から省くことには違いがある。AONの「時期を理由に省略してはならない」という規範と、実施順序を判断することの両方を保持する。

目的や責務の捉え直しが必要になる場合は、その意味の変更として扱う。費用や困難さを踏まえて目的そのものを再検討することと、同じ目的を掲げたまま未充足を充足と呼ぶことは区別される。関係する主体との契約が成立している場合には、定義の変更と合意の関係も引き受ける。

<a id="fulfilment"></a>
## 4．必要が満たされたことに即して評価する

充足は、目的と責務に照らして必要とされた意味が成立していることとして捉える。活動の評価は、何をしたかだけでなく、その活動によって何が成立したかとの対応に基づく。

成果物を作成したこと、決めた手順を実行したこと、確認項目を通過したことは、それぞれの実施や観測に関する事実である。それらがどの必要を満たした根拠となるかを結びつけて、充足を判断する。確認が表している範囲を保つことで、確かめた部分と、まだ確かめていない部分を扱える。

契約の履行と、その契約によって満たそうとした要求の充足にも、それぞれ対応先がある。実態が契約に適合していることを確かめた場合でも、要求理解の乖離があれば、主体が求めた結果との対応を改めて検討する必要がある。この区別は、[契約適合と要求達成を分離した既存判断](../../../knowledge/records/2026-09-15-design-principles-contract-decision/RECORD.md)にも現れている。

評価のための確認は、必要な意味を捉えられる対象と方法で行う。確認の数や形式を増やすこと自体を充足の代わりとせず、何を確かめる必要があるかに照らして選ぶ。具体的な試験、観察、レビュー、受け入れ条件の定め方は、対象ごとの方法論が引き受ける。

活動を支える環境や状態の確認には[状態と制御と再現の哲学](A3_STATE_CONTROL_DRAFT.md)を、確認の表現・根拠・評価履歴には[記録と真実と伝達の哲学](A3_TRUTH_SOURCE_DRAFT.md)を参照する。本体系は、それらの確認結果を必要と充足の関係に位置づける。

<a id="change-and-continuity"></a>
## 5．目的の変化と判断の継続を引き受ける

主体は時間やコンテキストによって変化し、目的や責務も捉え直され得る。必要性と充足の判断を継続するには、どの目的と責務に対する判断だったかを辿れることが必要になる。

当時の目的に対する不足が判明した場合、当時の必要性の認識に誤りがあった場合、新たな目的が加わった場合では、判断を更新する対象が異なる。これらを区別して、現在扱う意味と責務を明らかにする。新たな目的が生じたことを、そのまま過去の契約違反へ読み替えることも、現在の判断を過去に遡って当初からの意図とすることもできない。

判断を記録するときには、必要なものの一覧だけでなく、それを必要とした目的・責務、採用した手段、確認できた充足の範囲、残る必要との関係を伝える。その記録によって、後の主体は過去の判断を照合し、現在の条件のもとで続きを判断できる。記録と伝達の性質は[記録と真実と伝達の哲学](A3_TRUTH_SOURCE_DRAFT.md)を参照する。

具体的なWorkの進め方、実施計画、検証の形式、費用の見積もり、完了の報告方式は、この関係を活動の中で実現する方法論として定める。本体系は、その選択を通じて何の必要を満たし、何をもって充足とするかという判断を支える。
