# 環境と独立と再現の哲学〈仮称〉 — 第4哲学・編集用草案

**責務範囲：環境。真名・略名は検討中。本文はStage 2-A-3の編集用草案。** [環境の定義・独立に関する対話と草案反映の判断](../../../knowledge/records/2026-11-24-environment-definition-and-independence/RECORD.md)に基づき、環境の定義と性質を土台として本文を整える。標題は名称候補であり、正式な命名・本文全体の制定は別の判断とする。

本体系は、主体の活動の基盤となる環境について、SCBの主体・契約・境界・責務・内部自由の関係を展開する。環境を独立したまとまりとして成立させ、自ら引き受ける管理対象・状態・作用をその境界と対応させる。環境の清潔さ、契約の公布、制御、安全性、再現・復旧をこの対象に関係づけて扱う。

開発哲学が対象とするのは、主体が何らかの存在を作り、開発する営み一般である。開発対象や環境を構成する存在が物理的実体を伴うかどうかにかかわらず、意味・状態・関係を主体に相対して捉える。個別の分野における環境の構成、操作、管理手段は、哲学の示す関係を方法論が実現する。

[主体と契約と境界の哲学（SCB哲学）](A3_PHILOSOPHY_DRAFT.md)を根底とする。以下のD番号はSCBの定義を指す。[記録と真実と伝達の哲学（RTC哲学）](A3_TRUTH_SOURCE_DRAFT.md)が担う記録・伝達を参照しつつ、環境そのものの成立と作用を本体系で扱う。必要性・充足に関する判断では[第3哲学の現時点の草案](A3_PURPOSE_NECESSITY_DRAFT.md)を参照する。第3哲学の責務範囲と本質は検討中である。各説明の出典・導出・採否は[レビュー資料](A3_STATE_CONTROL_REVIEW.md)に示す。

<a id="conditions-and-state"></a>
## 1．環境の定義と性質

### 環境とは何か

**環境とは、ある主体が自身の欲求を実現するための活動を行うにあたり、その活動の基盤として捉える、諸存在およびそれらの状態・関係のまとまりである。**

環境には、主体が利用する存在、依存する存在、活動に影響や制約を与える存在、活動を行う場、それらの間に成立する契約や関係などが含まれる。構成する存在は物理的な実体を伴うものに限らない。法律、規則、契約、組織、知識、体系なども、主体の活動との関係において環境を構成し得る。

例えば、建設に用いる重機は環境の構成要素となる。その利用可能性、能力、使用権限は活動の成立条件に関わる。環境を構成する存在と、その存在の状態や関係による条件をともに捉える。

主体は環境のもとで活動し、環境を利用し、環境から作用を受ける。主体の活動も環境に作用し、その構成・状態・関係を変化させ得る。欲求の実現に向けて、環境そのものを整え、変更し、新たに成立させることもできる。環境は活動の基盤であると同時に、活動によって変化し得る存在である。

### 環境の主体相対性

SCBのまとまりは主体によって定義される仮想的な存在であり、環境もこの性質を持つ（D1.1・D1.2・D2.1・D2.2）。

**ある存在が環境であるかどうかは、その存在自体に固有の性質ではなく、主体の欲求と活動との関係によって定まる。**

同じ存在でも、ある主体にとっては環境であり、別の主体にとっては開発対象となり得る。同一個体であっても異なる主体として関われば、環境として捉えるまとまりは変化する。

例えば、建物は建設する主体にとって開発対象であり、その建物の中で活動する主体にとって環境となる。改修する主体にとっては、既存の環境であると同時に変更対象にもなり得る。環境の本質と境界は、主体が何を求め、どの活動を行うかとの関係において定まる。

### 環境の仮想と実態

環境というまとまりは主体の中の仮想側に定義される。対応する実態がある場合、主体は認識の撮影を通じて、その環境を情報Pとして捉える。撮影は不完全であり、認識した環境の内容と、対応する実態・作用との間に違いが生じ得る。環境の契約とその実態に乖離が生じる場合もある。両者の区別はD1.1・D4.2・D6.1に従う。

主体が認識していなかった存在や関係の作用が活動に及ぶこともある。その影響を認識することで、主体は環境を撮影し直し、定義や境界を再検討できる。

環境の定義は実態の成立に先行することもできる。主体が自身の欲求に照らして活動の基盤として求める環境を定義し、その環境を実現することには、SCBにおける仮想と実態、契約の成立と履行の関係が成立する（D3.1〜D3.3・D4.2）。例えば規則の意味・契約と、その内容を表現する外部記録、それに沿った実際の運用を関係づけて捉えられる。

### 環境のフラクタル性

ある環境の内部には複数のまとまりがあり、それぞれのまとまりに関わる主体は、自身の欲求と活動に応じた環境を定義できる。その環境自体が、さらに大きな環境を構成する一つの存在にもなり得る（D1.3・D2.3・D2.4）。

環境の高さや内側をどこまで扱うかは、基点主体の欲求と責務に相対する。ある主体が一つの存在として利用するまとまりについて、その存在を維持・開発する主体は、より詳細な環境を定義し得る。どの高さで環境を扱うかはSCBの境界面理論（第5章）に従う。

### 環境と管理責務

**環境として捉える範囲と、自らが管理責務を引き受ける境界は、それぞれ主体の欲求と契約に基づいて定まる。**

主体は自ら管理する存在を環境の構成要素として持つことも、他の主体が責務を引き受ける存在を環境の一部として利用することもできる。

例えば、活動に適用される法律は、その活動の環境の一部となり得る。その法律の制定・維持は、別の主体の責務として引き受けられ得る。

環境に何を含めるかという認識と、どの存在の維持・変更を引き受けるかを区別する。環境を構成する存在を利用し、変更し、委譲する際にも、その意味・責務と関係する契約に従って扱う。

<a id="environment-independence"></a>
## 2．環境の独立と管理責務

**自らの活動に必要な管理対象を、その管理責務を引き受けるまとまりの境界に収め、実際の管理と作用をその境界に対応させる。**

あるまとまりが管理を引き受けている状態・依存・資源の変更が、他のまとまりの成立条件を意図せず左右する構造では、独立した責務と内部自由を実態において保ちにくくなる。管理対象の帰属、実際に操作する範囲、作用の及ぶ範囲を、引き受ける責務と対応させることに意味がある。

環境として利用する外部の存在については、その存在との関係を定義し、成立した契約に即して利用する。依存先の意味・利用条件・担う責務を捉え、必要な条件を把握して扱う。依存先の内部の維持を自らの管理責務として引き受けるか、その責務を担う別主体へ委譲するかは、SCBの境界面理論に従う。

ここでの環境の独立は、契約として定めた関係のもとで、各まとまりがそれぞれの責務と内部自由を保てることである。共有実態を介して他のまとまりと関わる場合は、共通利用の意味・条件・責務を定義する（D4.3）。必要な分離・共有は、各まとまりが担う意味と実際の作用との関係に基づいて構成する。

環境の定義を活動の基盤として利用できる状態に保つ。必要な条件が特定の担い手の記憶や偶然の残存状態のみに支えられていれば、後の主体がその条件を整え直すことが難しくなる。何が環境を成立させ、その状態を誰が扱うかを捉えることは、独立した環境の維持・再現にも関わる。

<a id="cleanliness-and-procedure"></a>
## 3．環境の清潔さと相互干渉

**清潔さとは、あるまとまりの内部で生じた汚染を、そのまとまりが引き受ける境界の外側へ波及させないことである。**

ここで問うのは、内部の活動による変化が、その外側のまとまりにどのような作用として及ぶかである。相互作用の契約に照らし、外側へ引き受けさせるべきでない状態や作用を外へ波及させない。各まとまりが、相手の内部事情によって自らの状態や成立条件を意図せず変えられず、自身の契約に従って活動できることに価値がある。外へ及ぼすべき成果や、契約に基づく相互作用も、その関係に即して扱う。

境界の内側にどの状態を持つかは、外側との契約を履行する範囲で内部自由に属する。内部の状態を整理すること自体が、そのまとまりの清潔さの外部に対する責務を意味するわけではない。内側に独立したまとまりがあれば、それぞれの境界においてこの関係が再帰する（D3.4）。

活動の途中だけでなく、活動の終了や利用したものの返却の後に及ぶ作用も、その活動と他のまとまりとの契約に照らして引き受ける。活動が終わっても、残った状態が他者の活動に影響し得るためである。何を保持し、何を戻し、何を除くかは、その関係が要求する状態と責務によって定まる。

清潔さを実態において保つためには、状態の帰属や役割、共有・変更・片付けの範囲を把握することが役立つ。必要な状態や適切に共有される資源を維持すること、汚染の作用を分離し、必要に応じて除くことを、引き受けた責務に対応させる。

このように、清潔さは管理上の利便性に加え、環境同士の意図しない相互干渉を抑え、互いの独立と内部自由を保つための責務となる。

<a id="operations-and-effects"></a>
## 4．環境の契約の公布と作用の制御

環境と、その内側に定義した諸存在や操作は、それぞれの意味・責務・境界を持つ。主体がそれらを契約に沿って扱うためには、関わる主体にその契約を認識できる形で示す必要がある。適切な命名には、何であり、どのまとまりに属し、どの責務のもとで扱われるかを外部へ示す意味がある。

**命名によって契約を外部に示すことは、その契約を公布する一つの形である。** 契約内容の定義・外部への表現・関係する主体による認識や合意・実態の履行は、それぞれSCBの定義に従って捉える（D1.2・D3.1〜D3.3・D4.2）。認識と伝達の関係はRTCを参照する。名前によって示した意味と、実際の帰属・管理範囲・作用とを対応させる。

環境の操作や手順は、どの条件から始め、何を利用・変更し、どこへ作用し、どの状態を成立させるかという意味を持つ。操作の名前や入口を、その意味と対象に対応させる。同じ契約を担う操作については、関わる主体がその内部事情を毎回組み立て直さなくても扱えるようにする。

操作を制御するとは、引き受けた状態・操作・作用を、定義した契約と境界に対応させて扱うことである。表面上の操作対象と実効的な変更先・影響範囲は、必ずしも一致しない。共有実態や他の存在との関係を介して及ぶ作用も捉え、管理責務や権限と対応させる。実行可能であること、操作の権限があること、実際に操作が行われたことは、それぞれの関係に即して扱う。

意図した操作と生じた状態・作用の対応を必要な範囲で把握する。契約と実態の乖離を認識したときは、どの環境・操作・関係について乖離があるかを捉えて対処する。環境の定義と実態は、活動の中で維持・変更される対象である。

<a id="safety-and-recovery"></a>
## 5．安全性を環境の構造に組み込む

安全性を扱う際は、守る対象と、その対象に及ぶべきでない作用を明らかにする。変更する状態と保護する状態を区別し、通常の活動の経路において必要な保護が成立する構造を整える。環境の独立、清潔さ、作用の制御はこの保護にも関わる。

安全な操作を使いやすい経路とすることには意味がある。適切な命名・契約の公布、操作対象の識別、分離、作用範囲の限定によって保護を構成できれば、活動のたびに複雑な内部事情や担い手の記憶に頼る負担を減らせる。

確認や制限は、守る対象と避けるべき作用に対応させる。必要な確認が担う意味を保つ。具体的な保護構造や確認方法、何をどの範囲で許容するかは、対象と責務に応じて方法論が実現する。

想定外の状態や失敗が生じた場合にも、その作用が及んだ範囲を必要な程度に把握し、保護・診断・復旧を扱えるようにする。失敗を認識でき、必要な環境を再び整えるための条件を保持することには意味がある。復旧の操作自体についても、何を保持し、何を変更・破棄し、どこへ作用させるかを、他のまとまりの責務や契約との関係で捉える。

<a id="reproduction-and-resumption"></a>
## 6．環境の再現と活動の再開

環境の再現は、主体が活動の基盤として定義したまとまりを、必要な時点で再び成立させることを扱う。何を同じ環境として再現するかは、その主体の欲求と、環境の本質・契約に照らして定まる（D3.4・D6.4）。

環境を成立させるために必要な依存、構成、状態、操作や他の存在との関係を捉え、それらを再び整えられるものとして扱う。成果そのものを残すことと、その成果や活動を成立させる環境の条件を保持することは、それぞれの欲求・責務に応じて捉える。環境の内部をどの粒度まで同じにする必要があるかも、再現したい意味との対応によって定まる。

環境の変化には、意図した更新と、その実態と定義との関係がある。変更した条件・作用を捉え、維持すべき契約と対応させ、再現に必要な状態・関係の情報を保持する。外部の依存先についても、必要な契約・利用条件が成立するか、変化に対してどう関わるかを扱う。

活動を再開する際は、記録された到達状態や条件を参照しながら現在の実態を捉え、そのまま利用できるもの、再び整える必要があるもの、新しく判断するものを見出す。再開の目的と環境の再現に必要な意味を関係づけて扱う。

RTCは、後の主体が理解し判断できる記録を引き受ける。第4哲学は、記録を手掛かりに活動の環境そのものを成立させ、状態・作用を扱う。情報を保持・伝達する責務と、環境の実態を維持・再形成する責務の関係をここに捉える。

環境の具体的な構成、依存の管理、名前や入口の設け方、分離・保護・清掃、再現・診断・復旧の方法は、以上の関係に基づいて方法論が実現する。
