# 原記録を追加する手順

1. **取り込む範囲を確かめる。** 会話なら開始発言と終了発言を、資料なら対象の版と範囲を特定する。例えば「この提案から承認まで」と指定されたら、最初の提案、途中のやり取り、最後の承認までを一回分とする。
2. **記録スレッドを選ぶ。** 追記先の明示的な指定があればその親フォルダを使う。それ以外は、どの議論・調査の続きかを確かめ、[記録スレッドの定義](../models/RECORD_MODEL.md)に従って親を選ぶ。
3. **子フォルダを作る。** 選んだ親の中で、その取り込み日で最初の記録なら `01`、続きなら次の連番を使う。末尾に、同じ議論を11月28日に二度、翌日に一度記録した例を示す。
4. **原文と資料を収める。** 会話は発言者が分かる形で順に収め、対象の添付や資料は実ファイルを保存する。出典・収録範囲と、取得や転記に伴う制約を、本文と見分けられる位置に記す。
5. **元資料と照合する。** 会話では両端の発言と、その間のユーザー・AI双方の発言順と全文を確かめる。資料では対象の版と収録したファイルを確かめる。照合できなかった部分は注記に残す。

```text
records/
└── record-model-redesign/
    ├── 2026-11-28-01/
    ├── 2026-11-28-02/
    └── 2026-11-29-01/
```
