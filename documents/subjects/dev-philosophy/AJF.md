# 第4哲学　実現と判断と充足の哲学（AJF哲学）

2026年11月26日 仮決定版 [仮決定の記録](../../records/2026-11-26-sera-provisional-adoption/RECORD.md)

**SERA開発哲学の第4哲学。責務は実現。実現を表、判断を裏とする。** 一語での呼称は「実現の哲学」。真名の三語に Actualization / Judgment / Fulfillment を対応させ、略名を「AJF哲学」とする。[SERA開発哲学の命名・番号の採用記録](../../records/2026-11-28-sera-provisional-sources/files/documents/knowledge/records/2026-11-26-sera-philosophy-naming-and-order/RECORD.md)

**主体は、自らの欲求と引き受けた責務に照らして、何を満たそうとし、なぜそのように関わるのかを判断する。実現を問うときは、主体が選んだ関わりが、他の主体の働きやそのときの条件と結びついて、求めた意味を実際にどこまで成り立たせたかを捉える。**

SCBでは、「時刻を知りたい」という欲求と「時刻が分かるもの」という時計の本質は、同じ意味を主体とまとまりの両側から述べたものである。時計の本質が定まっているときにも、目の前の人が今の時刻を知るにはどうすればよいかという問いが残る。その人は腕時計を見ることも、人に尋ねることもできる。何を根拠にそう関わり、それで実際に時刻を知れたのか。AJFは、この選択とその働きの両方を扱う。[SCBの欲求と責務](SCB.md#d2-2)

時計を何と捉えるかにも、記録をどう解釈するかにも判断は働く。実現を表に置くのは、「この主体は何を実現しようとしているのか」が本体系の扱う範囲を定めるからである。行為を選ぶときには「この関わり方で何を満たせるか」を、結果を受け取るときには「この関わり方が何を満たしたか」を問う。同じ目的に向けて、選択にも充足の評価にも働く判断を、実現の裏に置く。

<a id="will-and-judgment"></a>
## 1．意思と判断

**誰にとって、何が満たされればよいのか。** 欲求は、主体がある存在に何を求めるかを表す。その求める意味を自らの営みで満たそうとするとき、それが目的となる。他の主体に対して何を引き受けたかは、誰と何について合意したかに即して捉える。[SCBの契約の成立](SCB.md#d3-2)

意思は、その目的に向けて自分がどう関わろうとするかに現れる。引き受けた責務は何を満たすべきかを定め、主体がそのとき把握した事情は、どの関わり方を選べばそれを満たし得るかを判断する根拠となる。

主体には、自ら手を加える、他の主体に委ねる、必要がすでに満たされているので手を加えずにおく、という選択があり得る。何を大切にしているかは、いくつかの欲求のうちどれを今回の目的として引き受けるかにも、その目的を満たす複数の手段からどれを選ぶかにも表れる。委ねた責務については、その責務を担う主体にも判断がある。[SCBの責務の内包・分割・委譲](SCB.md#d2-3)

行為に求める必然性は、その主体が、その状況で、なぜそうするのかという理由があることにある。同じ目的に対して理由のある選択が複数成り立つことも、結果に偶然が作用することもある。先を見通しきれない状況でも、主体がそのとき把握した事情をもとにどう関わるかを選ぶところに、意思は現れる。

<a id="purpose-and-responsibility"></a>
## 2．必要と選択

**その目的に何が必要で、どこを主体が選べるのか。** 「夜にも広場から時刻を読めるようにしたい」とする。この目的にとって必要なのは、暗くなっても広場から表示を読み取れることである。時計に照明を組み込むのは一つの手段であり、すでに街灯で十分に読める場所に時計を設ける選択もある。方式まで契約で定めた場合には、その方式を用いることも引き受けた責務となる。何が必要で、どこに選択の自由があるかは、誰のどの目的と契約を基準にしているかで変わる。[SCBの内部自由の契約相対性](SCB.md#d3-4)

<a id="aon"></a>
### AONの原則

> **AON — All and Only Necessary**
>
> 必要なものはすべて。必要なものだけ。
>
> 目的と責務に照らして必要なものを、実現の困難さや時期を理由に省略してはならない。
>
> 同時に、必要でないものを、可能性や容易さだけを理由に追加してはならない。
>
> 必要性の判断と、実現方法・費用・実施順序の判断を混同しない。

「すべて」と「だけ」は、同じ目的と責務に照らして判断する。必要な範囲には、表に現れる成果と、それを成り立たせる条件や保証が含まれる。たとえば夜間の読み取りを継続して引き受けるなら、頼りにした街灯が必要な時間帯に点灯することも判断の対象になる。[AONの採用原文（U3）](../../records/2026-11-28-sera-provisional-sources/files/documents/knowledge/records/2026-11-11-aon-principle-adoption-philosophy-baseline/USER_MESSAGES.md)

手段を加えるときは、それがどの必要を満たすのかを問う。すでに引き受けた保証を支える手段を外すときは、外した後も何がその保証を支えるのかを問う。広場の時計に予備灯を加える理由は、たとえば「一灯が消えても時刻を読める」という条件を引き受けているかで変わる。一方、時計の照明を外して街灯に頼るなら、必要な時間帯に街灯が点くことが根拠になる。消灯時刻が分からない間、街灯だけで足りるかは未判定である。**ある手段の要否を判断できない間も、夜に時刻を読めるようにするという責務は続く。**

<a id="means-and-feasibility"></a>
### 実現手段と必要な時期

ある手段に必要な条件が欠けたときは、同じ目的と契約を満たせる別の手段があるかを問う。代わりが見つかっていない間は、実現できるかどうかを保留できる。条件を満たす手段が一つも残っていないと分かれば、当初の条件での実現はできない。費用・困難さ・実施順序は、使える手段と進め方を判断する材料となる。期限や予算の上限を目的・契約に含めた場合は、その条件も充足の対象となる。

手段を延期しても、何をいつ満たす必要があるかは、引き受けた目的と契約から定まる。時計に照明を取り付ける日を延ばしても、それまで街灯の明かりで必要な時間帯を通じて時刻を読めたなら、その間の読み取りの必要は満たされている。必要な時に読めなかったなら、その時点の必要は未充足である。

事情に応じて目的そのものを見直すこともある。そのときは、何を必要としていたのか、これから何を引き受けるのかを区別する。すでに別の主体と契約している内容に変更が及ぶ場合は、その変更がどの合意に支えられるかを扱う。[SCBの契約の成立](SCB.md#d3-2)

<a id="fulfilment"></a>
## 3．充足と判断の更新

**実際に何が満たされ、その主体の選択はそこにどう働いたのか。** 充足とは、目的と責務に照らして必要とされた意味が、実際に満たされていることである。その充足を「この主体が実現した」と言うときは、その主体の働きかけが結果にどう結びついたかも問う。

通りがかった車の灯りで時計を一度だけ読めたなら、通行人の「今の時刻を知りたい」は満たされている。広場から見える位置に時計を設けた人の選択も、その一度の読み取りに寄与し得る。その人が「夜にも時刻を読める広場」を実現したと言えるかは、選んだ配置や照明が、引き受けた時間帯の読み取りを実際に支えているかによる。

時計が合意どおり正確な時刻を表示しているかと、広場にいる人が夜もそれを読めるかには、それぞれ確かめる対象がある。何の契約が履行されたか、誰の欲求がどこまで満たされたかを、その関係に即して捉える。実態が契約に対応していることと、主体がそう判断したことも区別する。何をしたか、何を観察できたか、それがどの充足を裏づけるかを結びつければ、確かめられた範囲と、判断を保留する範囲が分かる。[SCBの契約の履行](SCB.md#d3-3)

<a id="parts-and-whole"></a>
### 部分の履行と全体の充足

SCBでは、適切に分割した責務は、合わせて捉えたときに元の上位責務に収束する。実現についても、まず、誰が何を一つの全体として求めたかを確かめる。**複数の部分が結びついて初めてその全体が成り立つなら、部分の間に必要な関係も充足の対象に含まれる。** [SCBの責務の内包・分割・委譲](SCB.md#d2-3)

乗客が二つの列車を乗り継いで、予定時刻までに目的地へ着くことを望んでいる。その旅程が成り立つには、一方を降りてから他方の乗り場へ移る時間も要る。二つの列車がともに定刻に走っても、乗客が乗り継げず到着が遅れたなら、各区間の運行は約束どおりで、乗客が求めた時刻までの到着は未充足である。

次の判断を誰が引き受けるかは、もとの欲求と契約から辿れる。旅行会社が乗り継ぎを含む到着まで引き受けたなら、各社が運行を果たした後も、旅行会社には旅程全体について判断する責務が残る。乗客自身が二枚の切符を選び、各社がそれぞれの区間だけを引き受けたなら、次の便を探す理由は乗客自身の目的にある。複数の主体が接続を共同で引き受けたなら、それぞれにどの判断が残るかは、その合意の内容による。[SCBの契約の成立](SCB.md#d3-2)

予定時刻を過ぎた後にも、乗客には「今からでも目的地に着きたい」という欲求があり得る。別の便での到着はそれを満たす。「予定時刻までに着く」という当初の目的は未充足のまま残る。当時の結果は当時の目的に照らして捉え、次の行為は、今も続く欲求と引き受けている責務に照らして選ぶ。

<a id="change-and-continuity"></a>
### 当時の判断と、その後に分かったこと

なぜそう選んだかを問うときは、主体が当時何を把握し、何を根拠にしたかを辿る。その選択が妥当だったかを後から吟味するときは、当時確かめ得たのに見落とした事情も考慮できる。それを確かめる責務まであったかは、当時その主体が何を引き受けていたかによる。実際に何が満たされたかは、起きた結果に照らして捉える。理由のある試みが目的に届かない場合も、幸運に助けられた選択を見直す理由がある場合もある。

「夜は読めない」と分かったとき、夜間の読み取りが当初から必要だったなら、見落としていた条件に立ち返る。街灯の消灯時刻が変わったなら、新しい実態に対して同じ責務をどう果たすかを考える。広場を夜に使い始めたのが後からなら、新たな欲求に照らして目的や契約を捉え直す。どの時点の誰の欲求・責務に応えるかによって、更新する判断は変わる。[SCBの乖離と再定義](SCB.md#chapter-6)

判断の根拠と経過を後の主体にも辿れるようにする責務は[記録の哲学（RTC）](RTC.md)が、活動の基盤となる状態・依存・作用を扱う責務は[環境の哲学（EIC）](EIC.md)が担う。本体系では、それらを踏まえて、求めた意味のどこまでが満たされ、次にどう関わる理由があるかを問う。
